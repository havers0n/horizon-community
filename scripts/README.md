# 🔧 СКРИПТЫ ПРОЕКТА

## 📋 ОПИСАНИЕ

Эта директория содержит утилитарные скрипты для разработки, отладки и обслуживания проекта RolePlayIdentity.

## 🛠️ ДОСТУПНЫЕ СКРИПТЫ

### База данных
- **check-db-structure.js** - Проверка структуры базы данных
- **fix-database-schema.cjs** - Исправление схемы базы данных
- **check-bolo-schema.cjs** - Проверка схемы BOLO системы

### Пользователи
- **create-user.js** - Создание нового пользователя в системе

## 🚀 ИСПОЛЬЗОВАНИЕ

### Проверка структуры БД
```bash
node scripts/check-db-structure.js
```

### Исправление схемы БД
```bash
node scripts/fix-database-schema.cjs
```

### Проверка схемы BOLO
```bash
node scripts/check-bolo-schema.cjs
```

### Создание пользователя
```bash
node scripts/create-user.js
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Перед запуском** убедитесь, что настроены переменные окружения
2. **Backup данных** перед выполнением скриптов изменения БД
3. **Проверьте права доступа** к базе данных
4. **Тестируйте** на dev окружении перед prod

## 📝 ЛОГИ

Все скрипты выводят подробные логи выполнения. При ошибках проверьте:
- Подключение к БД
- Права доступа
- Корректность переменных окружения
