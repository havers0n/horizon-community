# Скрипты сборки и архивирования билд-артефактов

## Описание

Данные скрипты предназначены для автоматической сборки проекта и создания архива с билд-артефактами для деплоя на сервер.

## Доступные скрипты

### 1. Node.js версия (кроссплатформенная)
```bash
npm run build:archive
```

### 2. PowerShell версия (Windows)
```powershell
npm run build:archive:ps
```

## Функциональность

### Шаги выполнения:

1. **Сборка проекта**
   - Выполняется команда `npm run build`
   - Собираются все приложения: client, mdtclient, server

2. **Проверка билд-артефактов**
   - Проверяется существование папок:
     - `apps/client/dist` (обязательный)
     - `apps/mdtclient/dist` (обязательный)
     - `apps/server/dist` (опциональный)
     - `dist/apps/server` (опциональный)
     - `dist` (опциональный)

3. **Вывод структуры**
   - Отображается дерево файлов каждого найденного билда
   - Показываются размеры файлов и папок

4. **Создание архива**
   - Создается архив `deployment.tar.gz`
   - Включаются только реально существующие билд-артефакты
   - Старый архив удаляется перед созданием нового

5. **Проверка архива**
   - Проверяется создание архива
   - Выводится содержимое архива
   - Показывается размер архива

6. **Финальный отчет**
   - Сводка по всем включенным билдам
   - Информация о размере архива

## Требования

### Для Node.js версии:
- Node.js 18+
- npm
- tar (встроен в Windows 10+ и большинство Unix-систем)

### Для PowerShell версии:
- PowerShell 5.1+
- npm
- tar

## Использование

### Базовое использование:
```bash
# Node.js версия
npm run build:archive

# PowerShell версия (Windows)
npm run build:archive:ps
```

### Ручной запуск:
```bash
# Node.js
node scripts/build-and-archive.js

# PowerShell
powershell -ExecutionPolicy Bypass -File scripts/build-and-archive.ps1
```

## Выходные данные

### Успешное выполнение:
- Создается архив `deployment.tar.gz` в корне проекта
- Выводится подробный отчет о процессе
- Показывается структура включенных файлов

### Ошибки:
- Скрипт завершается с кодом ошибки 1
- Выводится подробное описание проблемы
- Указывается на каком этапе произошла ошибка

## Структура архива

Архив `deployment.tar.gz` содержит только необходимые для деплоя файлы:
```
deployment.tar.gz
├── apps/client/dist/          # Клиентское приложение (обязательно)
├── apps/mdtclient/dist/       # MDT клиент (обязательно)
├── apps/server/dist/          # Серверное приложение (если существует)
├── package.json               # Конфигурация проекта
├── package-lock.json          # Фиксация версий зависимостей
├── scripts/                   # Скрипты деплоя и утилиты
├── supabase/                  # Конфигурация базы данных
├── migrations/                # Миграции базы данных
├── docs/                      # Документация
├── README.md                  # Основная документация
├── ARCHITECTURE.md            # Архитектурная документация
└── QUICK_START_GUIDE.md       # Быстрый старт
```

**Исключено из архива:**
- `node_modules/` - зависимости устанавливаются на сервере
- `dist/` (корневая) - не создается в данном проекте
- Временные файлы и артефакты сборки

## Безопасность

- Скрипт проверяет существование каждого пути перед архивированием
- Не добавляются несуществующие файлы или папки
- Обрабатываются ошибки на каждом этапе
- Предоставляется подробная диагностика

## Интеграция с CI/CD

Скрипт можно использовать в GitHub Actions или других CI/CD системах:

```yaml

# Или для Windows

```

## Устранение неполадок

### Ошибка "Не найдено ни одного билд-артефакта"
- Убедитесь, что сборка прошла успешно
- Проверьте, что папки `apps/client/dist` и `apps/mdtclient/dist` существуют

### Ошибка при создании архива
- Проверьте наличие команды `tar`
- Убедитесь в правах на запись в текущую директорию

### Ошибка PowerShell Execution Policy
- Запустите PowerShell от имени администратора
- Выполните: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
