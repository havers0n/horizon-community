# Отчет о рефакторинге Supabase клиентов в сервисах

## Обзор выполненной работы

Успешно завершен рефакторинг всех сервисов в директории `apps/server/src/core/services/` для использования готовых Supabase клиентов вместо функции `createSupabaseClient`.

## Примененный паттерн

Для каждого сервиса были выполнены следующие изменения:

1. **Удален импорт старой функции**: `import { createSupabaseClient } from '../lib/supabase'`
2. **Добавлен импорт готовых клиентов**: `import { supabase, commonSupabase, mdtSupabase } from '../lib/supabase'`
3. **Удален конструктор** (если он больше не нужен)
4. **Присвоены готовые клиенты напрямую**: `private db = mdtSupabase;`
