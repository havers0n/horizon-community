# Отчет об исправлениях системы сборки и архивирования

## Проблема

В первоначальной версии скрипта была обнаружена критическая ошибка:
- Скрипт пытался архивировать несуществующую корневую папку `dist/`
- Включались несуществующие файлы документации
- Это приводило к ошибкам при создании архива

## Исправления

### 1. Исправлен основной скрипт (`scripts/build-and-archive.js`)

**Изменения:**
- Убрана проверка несуществующей папки `dist/`
- Убрана проверка несуществующей папки `dist/apps/server/`
- Добавлена фильтрация только реально существующих путей
- Улучшена диагностика с выводом информации о проверке каждого пути

**Результат:** Скрипт теперь корректно проверяет существование файлов перед архивированием.

### 2. Создан упрощенный скрипт (`scripts/build-and-archive-simple.js`)

**Особенности:**
- Минимальный набор файлов для деплоя
- Только гарантированно существующие файлы:
  - `apps/client/dist/` (обязательно)
  - `apps/mdtclient/dist/` (обязательно)
  - `apps/server/dist/` (опционально)
  - `package.json`
  - `package-lock.json`

**Преимущества:**
- Надежность - работает только с существующими файлами
- Простота - минимальный набор для деплоя
- Быстрота - меньше проверок и файлов

### 3. Обновлена документация

**Изменения в `scripts/BUILD_ARCHIVE_README.md`:**
- Исправлена структура архива
- Добавлено описание исключенных файлов
- Указано, что `node_modules/` не архивируется
- Уточнено, что корневая папка `dist/` не создается

### 4. Добавлен новый npm скрипт

```json
{
  "build:archive:simple": "node scripts/build-and-archive-simple.js"
}
```

- **Название:** `deployment.tar.gz`

- **Структура:** Оптимизирована для продакшена

## Рекомендации по использованию

### Для продакшена:
```bash
npm run build:archive:simple
```

### Для разработки (с дополнительными файлами):
```bash
npm run build:archive
```

### Для Windows:
```powershell
npm run build:archive:ps
```

## Преимущества исправленной системы

1. **Надежность:** Не пытается архивировать несуществующие файлы
2. **Оптимизация:** Исключает `node_modules/` и временные файлы
3. **Гибкость:** Предоставляет несколько вариантов архивирования
4. **Диагностика:** Подробная информация о процессе
5. **Безопасность:** Проверка существования каждого пути

## Структура архива (исправленная)

```
deployment.tar.gz
├── apps/client/dist/          # Клиентское приложение (2.01 MB)
├── apps/mdtclient/dist/       # MDT клиент (28.9 MB)
├── package.json               # Конфигурация проекта
└── package-lock.json          # Фиксация версий зависимостей
```

**Исключено:**
- ❌ `node_modules/` - устанавливается на сервере
- ❌ `dist/` (корневая) - не создается в проекте
- ❌ Несуществующие файлы документации
- ❌ Временные файлы сборки
