## 🚨 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. **UUID НАРУШЕНИЯ** (КРИТИЧНО)
- **Проблема:** Массовое использование `parseInt()` для ID
- **Файлы:** 15+ файлов в `apps/server/routes/`
- **Влияние:** Полное нарушение архитектуры UUID

### 2. **БЕЗОПАСНОСТЬ** (КРИТИЧНО)
- **Проблема:** Фронтенд делает прямые запросы к БД
- **Файлы:** `apps/mdtclient/src/features/citizen-portal/api/citizenApi.ts`
- **Влияние:** Нарушение безопасности, прямой доступ к данным

### 3. **ТИПИЗАЦИЯ** (КРИТИЧНО)
- **Проблема:** Фронтенд не использует типы из `packages/db-types`
- **Файлы:** `apps/client/src/lib/supabase.ts`, `apps/mdtclient/src/lib/supabase.ts`
- **Влияние:** Рассинхронизация типов

### 4. **АРХИТЕКТУРА** (КРИТИЧНО)
- **Проблема:** Бэкенд делает прямые запросы к таблицам
- **Файлы:** `apps/server/services/UserService.ts`, `apps/server/services/AuthService.ts`
- **Влияние:** Обход RPC архитектуры
