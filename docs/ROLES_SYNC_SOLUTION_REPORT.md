# Решение проблемы синхронизации ролей пользователей

## 🚨 Исходная проблема

**Вопрос:** "То есть каждый раз когда появляется новая роль ее нужно синхронизировать в db types? Или есть какой то подход?"

**Проблема:** В системе было **4 разных определения ролей** в разных местах:
1. База данных: `["citizen", "candidate", "staff", "admin"]`
2. Server: `UserRole` enum с ролями `citizen`, `candidate`, `staff`, `admin`
3. MDT Client: `UserRole` enum с ролями `Citizen`, `LEO`, `EMS/FD`, `Dispatch`, `Admin`
4. Personal Cabinet: локальные функции проверки ролей

Это приводило к:
- ❌ Несинхронизированным ролям между компонентами
- ❌ Ручной синхронизации при добавлении новых ролей
- ❌ Ошибкам типизации
- ❌ Сложности поддержки

## ✅ Реализованное решение

### 1. **Единый источник истины (Single Source of Truth)**

Создан централизованный файл `libs/shared-types/src/roles.ts`:

```typescript
// Основные роли пользователей (Personal Cabinet)
export const USER_ROLES = {
  CITIZEN: 'citizen',
  CANDIDATE: 'candidate', 
  STAFF: 'staff',
  ADMIN: 'admin'
} as const;

// MDT-специфичные роли (для экстренных служб)
export const MDT_ROLES = {
  CITIZEN: 'citizen',
  LEO: 'leo',
  EMS: 'ems',
  FD: 'fd',
  DISPATCH: 'dispatch',
  ADMIN: 'admin'
} as const;

// Функции для проверки ролей
export const isCandidate = (role: string): boolean => {
  return role === USER_ROLES.CANDIDATE;
};

export const isMember = (role: string): boolean => {
  return role === USER_ROLES.STAFF || role === USER_ROLES.ADMIN;
};

export const isCitizen = (role: string): boolean => {
  return role === USER_ROLES.CITIZEN;
};

// Маппинг для отображения
export const getRoleDisplayName = (role: string): string => {
  return ROLE_DISPLAY_NAMES[role] || 'Неизвестная роль';
};
```

### 2. **Автоматический скрипт синхронизации**

Создан скрипт `scripts/sync-roles.mjs` для автоматической синхронизации:

```bash
# Синхронизировать все роли
npm run sync:roles

# Добавить новую роль
npm run sync:roles -- --add-role=moderator
```

**Что делает скрипт:**
- ✅ Обновляет основной файл ролей
- ✅ Генерирует серверные enum'ы
- ✅ Обновляет MDT типы
- ✅ Создает миграции БД
- ✅ Генерирует TypeScript типы
