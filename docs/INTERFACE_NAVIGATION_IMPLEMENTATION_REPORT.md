## Архитектурные решения

### 1. Использование wouter для навигации
- **Причина**: Легковесная альтернатива React Router
- **Преимущества**: Меньший размер бандла, простота использования
- **Реализация**: `useLocation` хук для программной навигации

### 2. Компонентный подход
- **InterfaceSwitcher**: Переиспользуемый компонент для переключения интерфейсов
- **Контекстные кнопки**: Специфичные для каждого интерфейса кнопки навигации
- **Преимущества**: Модульность, легкое расширение

### 3. Адаптивный дизайн
- **InterfaceSwitcher**: Скрывает текст на мобильных устройствах
- **Иконки**: Всегда видимые для быстрой идентификации
- **Отзывчивость**: Работает на всех размерах экранов

## Структура навигации

```
Основной интерфейс (/dashboard)
├── Навигационное меню → MDT/CAD
├── InterfaceSwitcher → MDT System
└── InterfaceSwitcher → CAD System

MDT System (/mdt)
├── Кнопка "Вернуться в основной интерфейс"
└── Сайдбар → CAD System

CAD System (/cad)
└── Кнопка "MDT" в заголовке
```

## Технические детали

### Роутинг
```typescript
// apps/client/src/App.tsx
<Route path="/dashboard">
  <LazyPage component={Dashboard} />
</Route>
<Route path="/mdt">
  <LazyPage component={MDTDashboard} />
</Route>
<Route path="/cad">
  <LazyPage component={CAD} />
</Route>
```

### Навигация
```typescript
// Использование useLocation
const [, setLocation] = useLocation();
setLocation('/mdt'); // Переход в MDT
setLocation('/cad'); // Переход в CAD
setLocation('/dashboard'); // Возврат в основной интерфейс
```

### InterfaceSwitcher API
```typescript
<InterfaceSwitcher 
  variant="outline"    // default | outline | ghost
  size="sm"           // sm | md | lg
  className="custom-class"
/>
```

## Преимущества реализации

### 1. Пользовательский опыт
- **Интуитивная навигация**: Множественные способы переключения
- **Контекстная навигация**: Кнопки в логичных местах
- **Быстрый доступ**: InterfaceSwitcher всегда доступен

### 2. Разработка
- **Модульность**: Легко добавлять новые интерфейсы
- **Переиспользование**: Компоненты можно использовать в разных местах
- **Консистентность**: Единообразный подход к навигации

### 3. Производительность
- **Ленивая загрузка**: Интерфейсы загружаются по требованию
- **Плавная навигация**: Без перезагрузки страниц
- **Кэширование**: Состояние сохраняется между переключениями
