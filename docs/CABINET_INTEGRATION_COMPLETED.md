   - `getUserProfile()` - получение профиля пользователя
   - `updateUserProfile()` - обновление профиля

   - `getUserReports()` - получение отчетов пользователя

   - `getUserSettings()` - получение настроек пользователя
   - `updateUserSettings()` - обновление настроек
   - `getUserStats()` - получение статистики пользователя

2. **v1/cabinet роуты** - созданы 8 API эндпоинтов:
   - `GET /api/v1/cabinet/profile` - получение профиля
   - `PUT /api/v1/cabinet/profile` - обновление профиля
   - `GET /api/v1/cabinet/applications` - получение заявок
   - `GET /api/v1/cabinet/reports` - получение отчетов
   - `GET /api/v1/cabinet/departments` - получение департаментов
   - `GET /api/v1/cabinet/settings` - получение настроек
   - `PUT /api/v1/cabinet/settings` - обновление настроек
   - `GET /api/v1/cabinet/stats` - получение статистики

3. **DI-контейнер** - обновлен для включения CabinetService с правильными зависимостями

4. **Типы БД** - добавлены типы для `user_settings` и `user_activity` таблиц в `@roleplay-identity/db-types`

5. **Миграция БД** - создана полная миграция с RLS политиками, индексами и триггерами

6. **v1 роутер** - обновлен для подключения cabinet роутов

### 🎨 PERSONAL-CABINET (Port 3001)
1. **API клиент** - обновлен baseURL для подключения к server (`http://localhost:5000/api/v1`)

2. **Cabinet API сервис** - создан `cabinet-service.ts` с типизированными методами:
   - Полная типизация через `@roleplay-identity/db-types`
   - Обработка API ответов
   - Типы для обновления данных

3. **React Query хуки** - создан `useCabinet.ts` с полным набором хуков:
   - `useQuery` для получения данных
   - `useMutation` для обновления данных
   - Автоматическая инвалидация кэша
   - Обработка ошибок и уведомления

4. **UI компоненты** - созданы готовые компоненты:
   - `ProfileForm` - форма редактирования профиля
   - `UserStats` - отображение статистики пользователя
   - `UserApplications` - список заявок пользователя
   - `UserSettings` - управление настройками пользователя

5. **Экспорты** - обновлены индексы для экспорта новых модулей

6. **Переменные окружения** - обновлен `env.example` с правильным API URL
