# Отчет о реализации системы сборки и архивирования билд-артефактов

## Обзор

Реализована комплексная система для автоматической сборки проекта и создания архива с билд-артефактами для деплоя на сервер. Система включает проверку существования файлов, диагностику структуры и создание оптимизированного архива.

## Реализованные компоненты

### 1. Node.js скрипт (кроссплатформенный)
**Файл:** `scripts/build-and-archive.js`

**Функциональность:**
- Автоматическая сборка всех приложений проекта
- Проверка существования билд-артефактов
- Визуализация структуры файлов с размерами
- Создание архива `deployment.tar.gz`
- Подробная диагностика и отчетность

**Особенности:**
- Цветной вывод для лучшей читаемости
- Обработка ошибок на каждом этапе
- Проверка только реально существующих файлов
- Форматирование размеров файлов (B, KB, MB, GB)

### 2. PowerShell скрипт (Windows)
**Файл:** `scripts/build-and-archive.ps1`

**Функциональность:**
- Аналогичная функциональность Node.js версии
- Оптимизирован для Windows PowerShell
- Нативная работа с Windows API

### 3. GitHub Actions Workflow
**Файл:** `.github/workflows/build-and-archive.yml`

**Функциональность:**
- Автоматический запуск при push/PR
- Ручной запуск с выбором окружения
- Загрузка артефактов для последующего деплоя
- Интеграция с CI/CD pipeline

### 4. Документация
**Файл:** `scripts/BUILD_ARCHIVE_README.md`

**Содержание:**
- Подробное описание всех скриптов
- Инструкции по использованию
- Примеры интеграции с CI/CD
- Устранение неполадок

## Структура билд-артефактов

### Обязательные компоненты:
- `apps/client/dist/` - Клиентское приложение (React + Vite)
- `apps/mdtclient/dist/` - MDT клиент (React + Vite)

### Опциональные компоненты:
- `apps/server/dist/` - Серверное приложение (если существует)
- `dist/apps/server/` - Альтернативная локация серверного билда
- `dist/` - Дополнительные файлы проекта

## Использование

### Локальное использование:
```bash
# Node.js версия
npm run build:archive

# PowerShell версия (Windows)
npm run build:archive:ps
```

### CI/CD интеграция:
```yaml
# GitHub Actions
- name: Build and Archive
  run: npm run build:archive
```

## Преимущества реализации

1. **Автоматизация:** Полная автоматизация процесса сборки и архивирования
2. **Надежность:** Проверка существования файлов предотвращает ошибки
3. **Диагностика:** Подробная информация о процессе и структуре файлов
4. **Кроссплатформенность:** Работает на Windows, Linux, macOS
5. **Интеграция:** Готова к использованию в CI/CD системах
6. **Безопасность:** Не создает архив с несуществующими файлами

## Рекомендации по использованию

1. **Для разработки:** Используйте `npm run build:archive` для локальной сборки
2. **Для CI/CD:** Настройте GitHub Actions workflow для автоматического запуска
3. **Для деплоя:** Используйте созданный `deployment.tar.gz` для развертывания на сервере
4. **Мониторинг:** Следите за размером архива и структурой файлов
