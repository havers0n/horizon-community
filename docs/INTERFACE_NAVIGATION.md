# Навигация между интерфейсами

## Обзор

Проект содержит несколько специализированных интерфейсов, между которыми пользователи могут переключаться:

- **Основной интерфейс** (`/dashboard`) - Главная панель управления
- **MDT System** (`/mdt`) - Система управления данными (Mobile Data Terminal)
- **CAD System** (`/cad`) - Система диспетчеризации (Computer Aided Dispatch)

## Способы навигации

### 1. Interface Switcher (Рекомендуемый способ)

В правом верхнем углу навигационной панели расположен выпадающий список `InterfaceSwitcher`, который позволяет быстро переключаться между интерфейсами.

**Особенности:**
- Показывает текущий активный интерфейс
- Предоставляет краткое описание каждого интерфейса
- Поддерживает адаптивный дизайн (скрывает текст на мобильных устройствах)

### 2. Навигационное меню

В основном интерфейсе в навигационном меню добавлен пункт "MDT/CAD", который ведет к MDT системе.

### 3. Прямые ссылки в интерфейсах

#### В CAD System
- Кнопка "MDT" в заголовке для перехода в MDT System

#### В MDT System
- Кнопка "Вернуться в основной интерфейс" в верхней части дашборда
- Кнопка "CAD System" в боковой панели быстрых действий

## Техническая реализация

### Используемые технологии
- **Роутинг**: `wouter` (легковесная альтернатива React Router)
- **Навигация**: `useLocation` хук для программной навигации
- **Компоненты**: Переиспользуемые UI компоненты из `@/components/ui/`

### Структура файлов

```
apps/client/src/
├── components/
│   ├── InterfaceSwitcher.tsx     # Компонент переключения интерфейсов
│   └── Layout.tsx                # Основной layout с навигацией
├── pages/
│   ├── CAD.tsx                   # CAD интерфейс
│   └── Dashboard.tsx             # Основной дашборд
└── App.tsx                       # Роутинг приложения

apps/mdtclient/src/
└── widgets/
    └── mdt-dashboard/
        └── ui/
            └── MdtDashboardWidget.tsx  # MDT дашборд
```

### Роуты

```typescript
// apps/client/src/App.tsx
<Route path="/dashboard">
  <LazyPage component={Dashboard} />
</Route>
<Route path="/mdt">
  <LazyPage component={MDTDashboard} />
</Route>
<Route path="/cad">
  <LazyPage component={CAD} />
</Route>
```

## Рекомендации по использованию

### Для пользователей
1. Используйте Interface Switcher для быстрого переключения между интерфейсами
2. Обратите внимание на контекстные кнопки в каждом интерфейсе
3. Используйте браузерную навигацию (кнопки назад/вперед) для возврата к предыдущим страницам

### Для разработчиков
1. При добавлении новых интерфейсов обновляйте `InterfaceSwitcher`
2. Используйте `useLocation` из `wouter` для программной навигации
3. Добавляйте контекстные кнопки навигации в новые интерфейсы
4. Следите за консистентностью UI/UX между интерфейсами

## Расширение функциональности

### Добавление нового интерфейса

1. Создайте новый роут в `App.tsx`:
```typescript
<Route path="/new-interface">
  <LazyPage component={NewInterface} />
</Route>
```

2. Добавьте интерфейс в `InterfaceSwitcher`:
```typescript
const interfaces = [
  // ... существующие интерфейсы
  {
    id: 'new-interface',
    label: 'Новый интерфейс',
    path: '/new-interface',
    icon: NewIcon,
    description: 'Описание нового интерфейса'
  }
];
```

3. Добавьте кнопки навигации в соответствующие интерфейсы

### Кастомизация навигации

Компонент `InterfaceSwitcher` поддерживает различные варианты отображения:

```typescript
<InterfaceSwitcher 
  variant="outline"    // default | outline | ghost
  size="sm"           // sm | md | lg
  className="custom-class"
/>
```

## Безопасность

- Все переходы между интерфейсами проверяют аутентификацию пользователя
- Защищенные роуты автоматически перенаправляют на страницу входа
- Состояние пользователя сохраняется между интерфейсами

## Производительность

- Используется ленивая загрузка компонентов (`LazyPage`)
- Интерфейсы загружаются только при необходимости
- Кэширование данных между переключениями интерфейсов
