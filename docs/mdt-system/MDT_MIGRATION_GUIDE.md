# 🚀 РУКОВОДСТВО ПО ПРИМЕНЕНИЮ MDT МИГРАЦИИ

## 📋 ОБЗОР

Данное руководство описывает процесс применения миграции базы данных для MDT системы. Миграция добавляет 13 новых таблиц и необходимую инфраструктуру для полноценной работы MDT системы.

## 🔧 ПРЕДВАРИТЕЛЬНЫЕ ТРЕБОВАНИЯ

### 1. Переменные окружения
Убедитесь, что в файле `.env` установлены следующие переменные:

```env
# Supabase
VITE_SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# База данных (для Drizzle)
DATABASE_URL=postgresql://username:[YOUR-PASSWORD]@host:port/database
DB_PASSWORD=your-actual-password
```

### 2. Зависимости
Убедитесь, что установлены необходимые пакеты:

```bash
npm install @supabase/supabase-js dotenv
```

## 🚀 СПОСОБЫ ПРИМЕНЕНИЯ МИГРАЦИИ

### Способ 1: Автоматический скрипт (Рекомендуется)

#### Шаг 1: Запуск скрипта
```bash
node scripts/apply_mdt_migration.js
```

#### Шаг 2: Проверка результатов
Скрипт автоматически:
- ✅ Проверит подключение к базе данных
- ✅ Прочитает файл миграции
- ✅ Выполнит все SQL команды
- ✅ Покажет подробный отчет

### Способ 2: Через Drizzle CLI

#### Шаг 1: Запуск Drizzle скрипта
```bash
node scripts/apply_mdt_migration_drizzle.js
```

#### Шаг 2: Альтернативные команды Drizzle
```bash
# Применить миграции
npx drizzle-kit migrate

# Или применить схему напрямую
npx drizzle-kit push
```

### Способ 3: Ручное применение через Supabase Dashboard

#### Шаг 1: Откройте Supabase Dashboard
1. Перейдите на [supabase.com](https://supabase.com)
2. Войдите в свой аккаунт
3. Выберите проект

#### Шаг 2: Откройте SQL Editor
1. В левом меню выберите "SQL Editor"
2. Нажмите "New query"

#### Шаг 3: Примените миграцию
1. Скопируйте содержимое файла `supabase/migrations/004_mdt_system.sql`
2. Вставьте в SQL Editor
3. Нажмите "Run" для выполнения

## 📊 СОЗДАВАЕМЫЕ ТАБЛИЦЫ

Миграция создает следующие таблицы:

### Основные MDT таблицы:
- **`mdt_units`** - Юниты MDT системы
- **`mdt_calls_911`** - Вызовы 911
- **`mdt_call_attachments`** - Привязка юнитов к вызовам
- **`mdt_signals`** - Сигналы для экстренных служб
- **`mdt_signal_notifications`** - Уведомления о сигналах

### Отчеты и документы:
- **`law_reports`** - Отчеты правоохранительных органов
- **`ems_fd_reports`** - Отчеты EMS/FD служб
- **`notebook_notes`** - Заметки офицеров

### Системы управления:
- **`impound_lots`** - Штрафстоянки
- **`impounded_vehicles`** - Конфискованные ТС
- **`companies`** - Компании
- **`company_employees`** - Сотрудники компаний
- **`cargo_shipments`** - Грузоперевозки

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Ошибка подключения к базе данных
**Симптомы:** `❌ Ошибка подключения к базе данных`
**Решение:**
1. Проверьте переменные окружения
2. Убедитесь, что Supabase проект активен
3. Проверьте правильность URL и ключей

### Проблема 2: Таблицы уже существуют
**Симптомы:** `❌ Ошибка выполнения команды: relation already exists`
**Решение:**
1. Это нормально - таблицы уже созданы
2. Миграция безопасна для повторного выполнения
3. Проверьте, что все таблицы созданы корректно

### Проблема 3: Ошибки прав доступа
**Симптомы:** `❌ Ошибка выполнения команды: permission denied`
**Решение:**
1. Убедитесь, что используется `SUPABASE_SERVICE_ROLE_KEY`
2. Проверьте права доступа в Supabase Dashboard
3. Убедитесь, что RLS политики настроены правильно

### Проблема 4: Drizzle CLI не найден
**Симптомы:** `❌ Drizzle CLI не найден`
**Решение:**
```bash
# Установите Drizzle CLI
npm install -g drizzle-kit

# Или используйте npx
npx drizzle-kit --version
```
