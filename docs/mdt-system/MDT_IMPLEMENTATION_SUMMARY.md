### ✅ 2. СОЗДАН MDT СЕРВИС
**Файл:** `apps/server/services/MDTService.ts`

**Реализованные методы:**

#### Управление юнитами:
- `getActiveUnits()` - Получить активные юниты
- `createUnit()` - Создать новый юнит
- `updateUnitStatus()` - Обновить статус юнита
- `updateUnitLocation()` - Обновить местоположение
- `activatePanic()` - Активировать панику
- `deactivatePanic()` - Деактивировать панику

#### Управление вызовами:
- `getCalls()` - Получить все вызовы
- `createCall()` - Создать новый вызов
- `updateCall()` - Обновить вызов
- `assignUnitsToCall()` - Назначить юниты на вызов
- `updateCallStatus()` - Обновить статус вызова

#### Управление сигналами:
- `getActiveSignals()` - Получить активные сигналы
- `createSignal()` - Создать новый сигнал
- `updateSignal()` - Обновить сигнал
- `revokeSignal()` - Отозвать сигнал
- `notifySignal()` - Отправить уведомления
- `notifyPanic()` - Уведомления о панике

### ✅ 3. СОЗДАНЫ API ЭНДПОИНТЫ
**Файл:** `apps/server/routes/mdt.ts`

**Реализованные эндпоинты:**

#### MDT Units:
- `GET /api/mdt/units` - Получить активные юниты
- `POST /api/mdt/units` - Создать юнит
- `PUT /api/mdt/units/:id/status` - Обновить статус
- `PUT /api/mdt/units/:id/location` - Обновить местоположение
- `POST /api/mdt/units/:id/panic` - Активировать панику
- `DELETE /api/mdt/units/:id/panic` - Деактивировать панику

#### MDT Calls 911:
- `GET /api/mdt/calls` - Получить вызовы
- `POST /api/mdt/calls` - Создать вызов
- `PUT /api/mdt/calls/:id` - Обновить вызов
- `POST /api/mdt/calls/:id/assign` - Назначить юниты
- `PUT /api/mdt/calls/:id/status` - Обновить статус

#### MDT Signals:
- `GET /api/mdt/signals` - Получить сигналы
- `POST /api/mdt/signals` - Создать сигнал
- `PUT /api/mdt/signals/:id` - Обновить сигнал
- `DELETE /api/mdt/signals/:id` - Отозвать сигнал
- `POST /api/mdt/signals/:id/notify` - Отправить уведомления

#### Дополнительные эндпоинты:
- `GET /api/mdt/dashboard` - Данные для дашборда
- `GET /api/mdt/notifications` - Уведомления пользователя
- `PUT /api/mdt/notifications/:id/read` - Отметить как прочитанное
