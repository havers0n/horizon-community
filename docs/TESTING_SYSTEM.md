# Система тестирования RolePlayIdentity

## Обзор

Система тестирования позволяет создавать и проводить тесты для пользователей на основе их одобренных заявок. Система включает в себя управление сессиями тестирования, проверку прав доступа, тайминг и обработку результатов.

## Архитектура

### Компоненты

1. **TestService** - основной сервис для работы с тестами
2. **TestController** - контроллер для обработки HTTP-запросов
3. **Схемы валидации** - Zod схемы для валидации данных
4. **Маршруты** - Express маршруты для API

### База данных

#### Таблица `tests`
- `id` - уникальный идентификатор теста
- `title` - название теста
- `description` - описание теста
- `questions` - JSON с вопросами теста
- `is_active` - активен ли тест
- `time_limit` - лимит времени в секундах (по умолчанию 1200 = 20 минут)
- `passing_score` - проходной балл в процентах (по умолчанию 85)
- `required_application_type` - тип заявки, необходимой для доступа к тесту
- `created_at`, `updated_at` - временные метки

#### Таблица `test_sessions`
- `id` - уникальный идентификатор сессии
- `user_id` - ID пользователя
- `test_id` - ID теста
- `status` - статус сессии (in_progress, completed, expired, annulled)
- `start_time` - время начала сессии
- `end_time` - время окончания сессии
- `time_limit` - лимит времени для сессии
- `violation_reason` - причина нарушения (если сессия аннулирована)
- `created_at`, `updated_at` - временные метки

#### Таблица `test_results`
- `id` - уникальный идентификатор результата
- `session_id` - ID сессии
- `user_id` - ID пользователя
- `test_id` - ID теста
- `score` - количество правильных ответов
- `max_score` - максимальное количество баллов
- `percentage` - процент правильных ответов
- `passed` - прошел ли тест
- `answers` - JSON с ответами пользователя
- `time_taken` - время, затраченное на тест (в секундах)
- `status` - статус результата
- `comment` - комментарий к результату
- `created_at`, `updated_at` - временные метки

## API Endpoints

### Публичные маршруты (требуют аутентификации)

#### GET /api/v1/tests
Получить доступные тесты для пользователя.

**Ответ:**
```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "title": "Тест на полицейского",
      "description": "Тест для кандидатов в полицию",
      "time_limit": 1200,
      "passing_score": 85,
      "questions_count": 10
    }
  ]
}
```

#### GET /api/v1/tests/:id/results
Получить результат теста.

**Ответ:**
```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "score": 8,
    "max_score": 10,
    "percentage": 80,
    "passed": false,
    "time_taken": 900,
    "created_at": "2024-01-01T12:00:00Z"
  }
}
```

#### POST /api/v1/tests/:id/start
Начать сессию тестирования.

**Ответ:**
```json
{
  "success": true,
  "data": {
    "sessionId": "uuid",
    "questions": [
      {
        "id": "q1",
        "question": "Вопрос 1",
        "type": "single",
        "options": ["Вариант 1", "Вариант 2", "Вариант 3"]
      }
    ],
    "startTime": "2024-01-01T12:00:00Z",
    "timeLimit": 1200
  }
}
```

#### POST /api/v1/tests/:id/submit
Отправить ответы на тест.

**Запрос:**
```json
{
  "sessionId": "uuid",
  "answers": [
    {
      "questionId": "q1",
      "answer": "Вариант 1"
    }
  ]
}
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "score": 8,
    "totalQuestions": 10,
    "percentage": 80,
    "passed": false
  }
}
```

#### POST /api/v1/tests/sessions/:sessionId/violation
Сообщить о нарушении во время тестирования.

**Запрос:**
```json
{
  "reason": "Пользователь использовал внешние источники",
  "details": "Дополнительные детали"
}
```

### Административные маршруты (требуют роль admin)

#### GET /api/v1/tests/admin/all
Получить все тесты с статистикой.

#### POST /api/v1/tests/admin/create
Создать новый тест.

**Запрос:**
```json
{
  "title": "Новый тест",
  "description": "Описание теста",
  "questions": [
    {
      "id": "q1",
      "question": "Вопрос 1",

      "options": ["Вариант 1", "Вариант 2"],

      "points": 1
    }
  ],
  "timeLimit": 1200,
  "passingScore": 85
}
```

#### PUT /api/v1/tests/admin/:id
Обновить тест.

#### DELETE /api/v1/tests/admin/:id
Удалить тест.

#### GET /api/v1/tests/admin/results
Получить результаты тестов с фильтрами.

#### GET /api/v1/tests/admin/analytics
Получить аналитику тестов.

## Бизнес-логика

### Проверка прав доступа
1. Пользователь должен иметь одобренную заявку соответствующего типа
2. Тест должен быть активным
3. У пользователя не должно быть активной сессии для этого теста

### Управление сессиями
1. При начале теста создается сессия со статусом `in_progress`
2. Сессия автоматически помечается как `expired` при превышении времени
3. Сессия может быть аннулирована при нарушении правил

### Подсчет результатов
1. Сравнение ответов пользователя с правильными ответами
2. Подсчет процента правильных ответов
3. Определение прохождения теста на основе проходного балла

### Типы вопросов
- `single` - одиночный выбор
- `multiple` - множественный выбор
- `text` - текстовый ответ

## Безопасность

1. **Валидация данных** - все входящие данные валидируются через Zod схемы
2. **Проверка прав доступа** - каждый запрос проверяет права пользователя
3. **Защита от списывания** - система не отправляет правильные ответы на клиент
4. **Тайминг** - строгий контроль времени выполнения теста
5. **Аудит** - все действия логируются

## Мониторинг и аналитика

### Метрики
- Количество попыток прохождения теста
- Процент успешных прохождений
- Среднее время выполнения
- Статистика по вопросам

### Логирование
- Создание и завершение сессий
- Нарушения правил
- Ошибки системы

## Развертывание

### Миграции базы данных
```sql
-- Расширение таблиц для новой функциональности
ALTER TABLE "mdt"."tests" 
ADD COLUMN IF NOT EXISTS "is_active" boolean DEFAULT true,
ADD COLUMN IF NOT EXISTS "time_limit" integer DEFAULT 1200,
ADD COLUMN IF NOT EXISTS "passing_score" integer DEFAULT 85,
ADD COLUMN IF NOT EXISTS "required_application_type" text;

-- Создание индексов для оптимизации
CREATE INDEX IF NOT EXISTS "idx_tests_is_active" ON "mdt"."tests" ("is_active");
CREATE INDEX IF NOT EXISTS "idx_test_sessions_user_id" ON "mdt"."test_sessions" ("user_id");
```

### Конфигурация
- Время по умолчанию для тестов: 20 минут
- Проходной балл по умолчанию: 85%
- Максимальный размер ответов: 1MB

## Примеры использования

### Создание теста для полицейских
```json
{
  "title": "Тест на полицейского",
  "description": "Тест для кандидатов в полицию",
  "required_application_type": "police_officer",
  "questions": [
    {
      "id": "q1",
      "question": "Какое наказание предусмотрено за превышение скорости?",
      "type": "single",
      "options": ["Штраф", "Лишение прав", "Тюремное заключение"],
      "correct_answer": "Штраф",
      "points": 1
    }
  ],
  "timeLimit": 1800,
  "passingScore": 90
}
```

### Проведение тестирования
1. Пользователь получает список доступных тестов
2. Выбирает тест и начинает сессию
3. Отвечает на вопросы в рамках отведенного времени
4. Отправляет ответы и получает результат
5. При нарушении правил может быть создан репорт о нарушении
