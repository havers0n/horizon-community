# УПРОЩЁННАЯ СБОРКА FIVEM

## Обзор

Система сборки FiveM была значительно упрощена. Теперь используется единая конфигурация Vite с автоматическим определением режима сборки.

## Новые возможности

### ✅ Автоматическое определение режима
- **Браузер:** `npm run build`
- **FiveM:** `npm run build:fivem`

### ✅ Автоматическое копирование
- Файлы автоматически копируются в FiveM ресурс
- Не нужно запускать отдельные скрипты

### ✅ Оптимизация для FiveM
- Отключены sourcemap для уменьшения размера
- Простые имена файлов без хешей
- Оптимизированный target (ES2015)

## Команды сборки

### Основные команды

```bash
# Сборка для браузера
npm run build

# Сборка для FiveM (с автоматическим копированием)
npm run build:fivem

# Сборка всех приложений + FiveM
npm run build:deploy

# Режим разработки с автопересборкой
npm run build:fivem:watch
```

### Команды в папке mdtclient

```bash
cd apps/mdtclient

# Сборка для браузера
npm run build

# Сборка для FiveM
npm run build:fivem

# Режим разработки с автопересборкой
npm run build:watch
```

## Конфигурация Vite

### Автоматическое определение режима
```typescript
const isNUI = process.env.NUI === 'true' || process.env.BUILD_TARGET === 'fivem';
```

### Оптимизации для FiveM
```typescript
build: {
  outDir: isNUI ? "dist-nui" : "dist",
  sourcemap: !isNUI, // Отключено для FiveM
  base: isNUI ? './' : '/',
  target: isNUI ? 'es2015' : 'esnext',
}
```

## Проблемы и решения

### Проблема: Файлы не копируются
**Решение:** Проверьте что `BUILD_TARGET=fivem` установлен

### Проблема: Большой размер файлов
**Решение:** Проверьте что sourcemap отключен для FiveM

### Проблема: Ошибки в FiveM
**Решение:** Проверьте что target установлен в ES2015
