# 🚔 Система LAW отчетов - Реализация

## Описание

Реализована полнофункциональная система составления отчетов для панели управления LAW в MDT Client. Система позволяет создавать детальные отчеты об инцидентах с возможностью указания информации о подозреваемых, транспорте, оружии и изъятых предметах.

## Основные функции

### 1. Составление отчета
- **Двухстраничная форма** с пошаговым заполнением
- **Валидация данных** на каждой странице
- **Интуитивный интерфейс** с подсказками

### 2. Первая страница - Основная информация
- **Имя гражданского** - обязательное поле
- **Адрес инцидента** - обязательное поле
- **Время инцидента** - обязательное поле с выбором даты и времени
- **Тип инцидента** - выпадающий список с предустановленными типами
- **Статья** - выбор из уголовного кодекса с отображением штрафа и срока
- **Тип санкции** - предупреждение, арест или штраф
- **Описание ситуации** - текстовое поле для детального описания

### 3. Вторая страница - Дополнительная информация
- **Транспорт подозреваемого** (опционально):
  - Номерной знак
  - Модель
  - Цвет
  - Флаги: "Эвакуирован", "Угнанное транспортное средство"
- **Изъятые вещи** - динамический список с возможностью добавления/удаления
- **Оружие подозреваемого** (опционально):
  - Серийный номер
  - Модель
  - Тип оружия
  - Флаги: "Имеет серийный номер", "Зарегистрировано"

### 4. Просмотр отчетов
- **Список всех отчетов** с краткой информацией
- **Детальный просмотр** каждого отчета
- **Фильтрация и поиск** (планируется)
- **Редактирование и удаление** отчетов

## Техническая реализация

### Новые типы данных
```typescript
interface LawReport {
  id: string;
  citizenName: string;
  incidentAddress: string;
  incidentTime: string;
  incidentType: string;
  penalCode: string;
  sanctionType: 'warning' | 'arrest' | 'fine';
  description: string;
  suspectVehicle?: {
    plate: string;
    model: string;
    color: string;
    isImpounded: boolean;
    isStolen: boolean;
  };
  seizedItems: string[];
  suspectWeapon?: {
    serialNumber: string;
    model: string;
    type: string;
    hasSerialNumber: boolean;
    isRegistered: boolean;
  };
  createdAt: string;
  author: string;
}
```

### Компоненты
- `LawReportForm` - основная форма составления отчета
- `LawReportsList` - список отчетов с детальным просмотром
- `LawReportDetailsModal` - модальное окно с полной информацией об отчете

### Константы
- `INCIDENT_TYPES` - предустановленные типы инцидентов
- `MOCK_LAW_REPORTS` - моковые данные для демонстрации

### Локализация
Добавлены ключи локализации для русского и английского языков:
- `lawControl.createReport` - Составить отчет
- `lawControl.reportsList` - Отчеты
- `lawControl.newReport` - Новый отчет
- И многие другие...

## Интеграция с LAW Control Panel

Система отчетов интегрирована в существующую LAW Control Panel:
- Добавлены новые вкладки "Составить отчет" и "Отчеты"
- Сохранена единообразная навигация
- Поддерживается переключение между разделами

## Функциональность

### Создание отчета
1. Переход в раздел "Составить отчет"
2. Нажатие кнопки "Новый отчет"
3. Заполнение первой страницы (обязательные поля)
4. Переход на вторую страницу (опциональные поля)
5. Завершение создания отчета

### Просмотр отчетов
1. Переход в раздел "Отчеты"
2. Просмотр списка всех отчетов
3. Клик на кнопку "Просмотр" для детальной информации
4. Возможность редактирования или удаления

### Валидация
- Проверка обязательных полей на первой странице
- Кнопка "Далее" активна только при заполнении всех обязательных полей
- Возможность возврата на предыдущую страницу для исправлений

## Использование

### Для пользователей
1. Войдите в MDT Client под ролью LEO
2. Перейдите в раздел "LAW CONTROL PANEL"
3. Выберите вкладку "Составить отчет"
4. Нажмите "Новый отчет" и заполните форму

### Для разработчиков
```typescript
// Создание нового отчета
const newReport: LawReport = {
  id: `law_report_${Date.now()}`,
  citizenName: 'John Doe',
  incidentAddress: '123 Main St',
  incidentTime: '2024-01-15T14:30:00Z',
  incidentType: 'Превышение скорости',
  penalCode: '2-5. Reckless Driving',
  sanctionType: 'fine',
  description: 'Описание инцидента',
  createdAt: new Date().toISOString(),
  author: 'Officer Johnson'
};
```
