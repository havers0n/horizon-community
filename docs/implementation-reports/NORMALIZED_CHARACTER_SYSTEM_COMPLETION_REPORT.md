## API эндпоинты

### Персонажи
- `GET /api/characters` - список всех персонажей
- `GET /api/characters/my` - персонажи пользователя
- `POST /api/characters` - создание персонажа
- `GET /api/characters/:id` - получение персонажа
- `GET /api/characters/:id/full` - полная информация с профилями
- `PUT /api/characters/:id` - обновление персонажа
- `DELETE /api/characters/:id` - удаление персонажа

### Профили LEO
- `GET /api/characters/:id/leo-profile` - получение профиля LEO
- `POST /api/characters/:id/leo-profile` - создание профиля LEO
- `PUT /api/characters/:id/leo-profile` - обновление профиля LEO
- `DELETE /api/characters/:id/leo-profile` - удаление профиля LEO

### Профили EMS/FIRE
- Аналогичные эндпоинты для EMS и FIRE профилей

### Дополнительные
- `GET /api/characters/search/:query` - поиск персонажей
- `GET /api/characters/filter` - фильтрация персонажей
- `GET /api/characters/:id/legacy` - данные в старом формате
- `GET /api/characters/stats` - статистика

## Примеры использования

### Создание персонажа с профилем LEO
```typescript
// 1. Создаем персонажа
const character = await fetch('/api/characters', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: JSON.stringify({
    firstName: 'John',
    lastName: 'Doe',
    dateOfBirth: '1990-01-01',
    gender: 'male',
    address: '123 Main St'
  })
});

// 2. Создаем профиль LEO
const leoProfile = await fetch(`/api/characters/${character.id}/leo-profile`, {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: JSON.stringify({
    badgeNumber: 'LSPD-001',
    departmentId: 1,
    callsign: '1-ADAM-12'
  })
});

// 3. Получаем полную информацию
const fullCharacter = await fetch(`/api/characters/${character.id}/full`);
```
