# Отчет о добавлении раздела "Создание офицера" в гражданский портал

## Описание изменений

В гражданский портал MDT Client был добавлен новый раздел "Создание офицера" с полнофункциональной формой для создания офицеров правоохранительных органов.

## Реализованная функциональность

### 1. Навигация
- Добавлен новый пункт меню "Создание офицера" в сайдбар гражданского портала
- Использована иконка Shield для визуального обозначения
- Раздел интегрирован в существующую систему навигации

### 2. Форма создания офицера
Форма содержит следующие поля:
- **Номер значка** - автоматически генерируемый 5-значный номер (10000-99999)
- **Позывной. Символ 1** - первый символ позывного (максимум 1 символ)
- **Позывной. Символ 2** - второй символ позывного (максимум 1 символ)
- **Департамент** - выпадающий список (LSPD, BCSO, LSFD)
- **Подразделение** - выпадающий список с различными подразделениями

### 3. Функции формы
- **Автогенерация номера значка** - кнопка для генерации случайного 5-значного номера
- **Валидация полей** - кнопка "Создать" активна только при заполнении всех полей
- **Модальное окно** - форма отображается в модальном окне поверх основного интерфейса
- **Локализация** - полная поддержка русского и английского языков

## Структура данных офицера

```typescript
interface OfficerData {
    badgeNumber: string;      // 5-значный номер значка
    callsignSymbol1: string;  // Первый символ позывного
    callsignSymbol2: string;  // Второй символ позывного
    department: string;       // Департамент (LSPD/BCSO/LSFD)
    subdivision: string;      // Подразделение
}
```
