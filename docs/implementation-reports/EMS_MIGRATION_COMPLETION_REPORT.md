3. **Управление юнитами:**

   - Управление статусами (доступен, в пути, недоступен)
   - Информация об экипаже и оборудовании

4. **Рапорты:**
   - Создание медицинских отчетов
   - Просмотр и редактирование отчетов
   - Фильтрация и поиск

5. **Сотрудники:**
   - Управление персоналом EMS
   - Поиск и фильтрация сотрудников
   - Информация о квалификациях

6. **Журнал смен:**
   - Управление сменами EMS

   - Фильтрация по типам и статусам

7. **Пациенты:**

   - Статистика пациентов
