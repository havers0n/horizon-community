# 🎨 Playground - Эксперименты с интерфейсами MDT

## Обзор

Playground - это специальная среда для экспериментов с интерфейсами и компонентами MDT системы. Здесь вы можете тестировать новые идеи, прототипировать интерфейсы и изучать возможности компонентов.

## 🚀 Как запустить

### 1. Запуск dev сервера
```bash
cd apps/mdtclient
npm run dev
```

### 2. Доступ к Playground
1. Откройте браузер и перейдите на `http://localhost:3001`
2. Войдите в систему (если требуется)
3. Выберите "Ядро экстренных служб"
4. Нажмите на "🎨 Playground" в списке департаментов

## 📁 Структура Playground

### Основной Playground (`/src/pages/Playground.tsx`)
- **Кнопки**: Все варианты кнопок с разными размерами и состояниями
- **Формы**: Поля ввода, чекбоксы и другие элементы форм
- **Бейджи**: Различные типы бейджей для статусов
- **Таблицы**: Примеры таблиц с данными
- **Эксперименты**: Карточки сотрудников, транспорта и зданий

### Advanced Playground (`/src/pages/AdvancedPlayground.tsx`)
- **Дашборд**: Статистика и быстрые действия
- **Инциденты**: Управление инцидентами с поиском и фильтрацией
- **Подразделения**: Список активных подразделений и карта
- **Аналитика**: Графики и экспорт данных

## 🧩 Доступные компоненты

### Атомы (Atoms)
- `Button` - Кнопки с различными вариантами и размерами
- `Input` - Поля ввода с иконками
- `Card` - Карточки для контента
- `Badge` - Бейджи для статусов
- `Checkbox` - Чекбоксы
- `Table` - Таблицы с данными

### Иконки
Используются иконки из библиотеки `lucide-react`:
- `Search`, `Plus`, `Trash2` - Действия
- `Settings`, `User`, `Car`, `Building` - Объекты
- `MapPin`, `Clock`, `AlertTriangle` - Статусы

## 🎯 Примеры использования

### Создание новой кнопки
```tsx
import { Button } from '@/shared/ui/atoms/Button/Button';
import { Plus } from 'lucide-react';

<Button 
  variant="primary" 
  size="lg" 
  leftIcon={<Plus className="h-4 w-4" />}
  onClick={() => console.log('Кнопка нажата')}
>
  Добавить новый элемент
</Button>
```

### Создание карточки с данными
```tsx
import { Card } from '@/shared/ui/atoms/Card/Card';
import { Badge } from '@/shared/ui/atoms/Badge/Badge';

<Card className="p-4">
  <div className="flex items-center justify-between">
    <div>
      <h3 className="font-medium">Название</h3>
      <p className="text-sm text-gray-500">Описание</p>
    </div>
    <Badge variant="default">Статус</Badge>
  </div>
</Card>
```

## 🔧 Настройка и кастомизация

### Добавление новых компонентов
1. Создайте компонент в соответствующей директории
2. Добавьте его в Playground для тестирования
3. Создайте story файл для Storybook (опционально)

### Изменение стилей
- Используйте Tailwind CSS классы для стилизации
- Следуйте существующим паттернам дизайна
- Тестируйте на разных размерах экранов

## 📱 Адаптивность

Все компоненты в Playground адаптивны и работают на:
- Мобильных устройствах (320px+)
- Планшетах (768px+)
- Десктопах (1024px+)
- Больших экранах (1440px+)

## 🎨 Цветовая схема

### Основные цвета
- **Primary**: Синий (#3B82F6)
- **Secondary**: Серый (#6B7280)
- **Danger**: Красный (#EF4444)
- **Success**: Зеленый (#10B981)
- **Warning**: Оранжевый (#F59E0B)

### Темы
- **Light**: Светлая тема с белым фоном
- **Dark**: Темная тема с темным фоном (автоматически)
