## 🎯 Примененные эффекты

### **Карточки (Card)**
```tsx
// Glass эффект - прозрачность с размытием
<Card variant="glass">

// Neon эффект - неоновое свечение  
<Card variant="neon">

// Digital эффект - максимальный цифровой вид
<Card variant="digital">

// Secondary - градиентный фон
<Card variant="secondary">
```

### **Кнопки (Button)**
```tsx
// Glass кнопка с прозрачностью
<Button variant="glass">

// Neon кнопка с свечением
<Button variant="neon">

// Primary с градиентом и тенями
<Button variant="primary">
```

### **Поля ввода (Input)**
```tsx
// Glass input с размытием
<Input variant="glass">

// Neon input с свечением
<Input variant="neon">
```

### **CSS классы**
```css
/* Пульсация с свечением */
.pulse-glow

/* Эффект печати */
.typewriter

/* Свечение */
.glow, .glow-primary, .glow-danger

/* Улучшенные тени */
.shadow-3xl, .shadow-4xl
```
