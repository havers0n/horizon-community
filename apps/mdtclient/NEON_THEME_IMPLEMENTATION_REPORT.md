## Технические особенности

### CSS Эффекты
- **Glassmorphism**: Полупрозрачность + размытие фона
- **Неоновое свечение**: Многослойные box-shadow с анимацией
- **Параллакс**: Анимированный фон с transform
- **Плавающие элементы**: Анимация translateY с rotateX

### Анимации
- `neonPulseCyan/Pink/Purple/Green/Orange` - пульсация свечения
- `neonParallax` - параллакс фона
- `floatingCard` - плавающие карточки
- `digitalFlicker` - цифровое мерцание

### Цветовая палитра
- **Cyan**: #00FFFF (основной неоновый)
- **Pink**: #FF00FF (акцентный)
- **Purple**: #8000FF (специальный)
- **Green**: #00FF00 (успех)
- **Orange**: #FFA500 (предупреждение)

## Как использовать

1. **Активировать неоновую тему:**
   ```tsx
   const { setTheme } = useTheme();
   setTheme('neon');
   ```

2. **Применить неоновые компоненты:**
   ```tsx
   <Button variant="neon">Неоновая кнопка</Button>
   <Card variant="glass">Стеклянная карточка</Card>
   <Input variant="neon" placeholder="Неоновое поле" />
   ```

3. **Добавить переключатель темы:**
   ```tsx
   <ThemeToggle showLabels />
   ```

4. **Посмотреть демо:**
   Открыть страницу `NeonThemeDemo` для полной демонстрации всех эффектов.
