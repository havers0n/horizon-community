# 🎨 MDT Component Playground - Руководство

## Обзор

MDT Component Playground - это простой HTML-файл для быстрого тестирования и демонстрации UI-компонентов без сложной настройки Storybook.

## 🚀 Быстрый запуск

### Вариант 1: Простой запуск
```bash
# Откройте файл в браузере
open playground.html
```

### Вариант 2: Через HTTP сервер
```bash
# Установите http-server (если не установлен)
npm install -g http-server

# Запустите сервер
npx http-server . -p 8080 -o playground.html
```

### Вариант 3: Через Live Server (VS Code)
1. Установите расширение "Live Server"
2. Правый клик на `playground.html`
3. Выберите "Open with Live Server"

## 📋 Доступные компоненты

### 1. Кнопки (Buttons)
- **Primary** - Основные действия
- **Secondary** - Вторичные действия
- **Danger** - Опасные действия (удаление)
- **Ghost** - Прозрачные кнопки
- **Outline** - Контурные кнопки
- **Размеры**: Small, Medium, Large

### 2. Карточки (Cards)
- Базовые карточки с заголовком и содержимым
- Карточки с действиями
- Адаптивная сетка

### 3. Бейджи (Badges)
- **Primary** - Основные метки
- **Success** - Успешные статусы
- **Warning** - Предупреждения
- **Danger** - Ошибки
- Статусы: Активен, В ожидании, Заблокирован, Новый

### 4. Поля ввода (Inputs)
- Текстовые поля
- Email поля
- Поля паролей
- Текстовые области

### 5. Макеты (Layouts)
- Двухколоночный макет (сайдбар + контент)
- Трехколоночный макет
- Адаптивные сетки

## 🔧 Настройка и кастомизация

### Добавление новых компонентов

1. **Добавьте CSS стили** в секцию `<style>`:
```css
.new-component {
    /* ваши стили */
}
```

2. **Добавьте новую вкладку** в JSX:
```jsx
<div 
    className={`tab ${activeTab === 'new' ? 'active' : ''}`}
    onClick={() => setActiveTab('new')}
>
    Новый компонент
</div>
```

3. **Добавьте контент вкладки**:
```jsx
<div className={`tab-content ${activeTab === 'new' ? 'active' : ''}`}>
    <div className="component-section">
        <h2 className="component-title">Новый компонент</h2>
        {/* ваш компонент */}
    </div>
</div>
```

### Интеграция с проектом

Для использования компонентов в основном проекте:

1. **Скопируйте CSS стили** в ваш основной CSS файл
2. **Адаптируйте классы** под вашу архитектуру
3. **Используйте Tailwind CSS** для консистентности
