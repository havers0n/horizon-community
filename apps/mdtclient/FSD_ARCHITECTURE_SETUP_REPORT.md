## 🔧 Технические детали

### Структура модуля
Каждый модуль содержит:
```
module/
├── model/          # Бизнес-логика, типы, селекторы
├── api/            # API методы
├── ui/             # UI компоненты
└── index.ts        # Публичный API модуля
```

### Правила зависимостей
- ✅ Каждый слой может зависеть только от слоев ниже себя
- ✅ Запрещены циклические зависимости
- ✅ Shared слой не зависит ни от кого

### Barrel Exports
Все модули экспортируют свой публичный API через index.ts файлы, что обеспечивает:
- Чистые импорты: `import { Button } from '@/shared/ui/atoms'`
- Инкапсуляцию внутренней структуры
- Удобное рефакторинг

### EMS/FD разделение
```typescript
// EMS система
import { EmsPortal } from '@/widgets/ems-portal';
import { PatientManagement } from '@/features/ems-system';
import { Patient } from '@/entities/patient';

// FD система
import { FdPortal } from '@/widgets/fd-portal';
import { FireIncidentManagement } from '@/features/fd-system';
import { FireIncident } from '@/entities/fire-incident';
```
