# Отчет о решении проблемы навигации в MDT системе

## 🚨 Проблема

Пользователь не мог вернуться к выбору департаментов и модулей после входа в MDT Portal. Интерфейс "Synapse Terminal" с оперативным дашбордом работал корректно, но отсутствовала возможность навигации назад.

## 🔍 Анализ проблемы

### Текущая архитектура навигации:

1. **Главная страница** (`DashboardPage`) - выбор департаментов и модулей
2. **MDT Portal** (`MdtPortal`) - оперативный дашборд и модули
3. **Проблема:** После входа в MDT Portal не было способа вернуться к выбору

### Структура навигации:

```
DashboardPage (выбор департаментов/модулей)
    ↓
MdtPortal (оперативный дашборд)
    ❌ Нет пути назад
```

## ✅ Решение

### 1. Добавлена кнопка возврата в сайдбар

**Файл:** `src/widgets/mdt-portal/ui/MdtSidebar.tsx`

```typescript
// Кнопка возврата к выбору департаментов
<div className="mb-4">
  <Button 
    variant="outline"
    size="sm" 
    onClick={handleBackToDepartments}
    className="w-full justify-start text-xs"
  >
    <ArrowLeft className="h-3 w-3 mr-2" />
    Выбор департаментов
  </Button>
</div>
```

### 2. Реализована гибкая навигация

**Поддержка двух режимов:**
- **Режим 1:** Возврат к выбору модулей (в рамках приложения)
- **Режим 2:** Возврат на главную страницу (через React Router)

```typescript
const handleBackToDepartments = () => {
  if (onBackToModules) {
    // Если передана функция обратного вызова, используем её
    onBackToModules();
  } else {
    // Иначе используем React Router для навигации
    navigate('/');
  }
};
```

### 3. Обновлена архитектура компонентов

**Файл:** `src/widgets/mdt-portal/ui/MdtPortal.tsx`

```typescript
interface MdtPortalProps {
  onBackToModules?: () => void;
}

export const MdtPortal: React.FC<MdtPortalProps> = ({ onBackToModules }) => {
  // ...
  return (
    <div className="flex h-screen bg-transparent">
      <MdtSidebar onBackToModules={onBackToModules} />
      {/* ... */}
    </div>
  );
};
```

**Файл:** `src/pages/DashboardPage.tsx`

```typescript
if (selectedDepartment === 'pd' && selectedModule === 'mdt-portal') {
  return (
    <MdtPortal 
      onBackToModules={() => setSelectedModule('')}
    />
  );
}
```

## 🎯 Результат

### Новая структура навигации:

```
DashboardPage (выбор департаментов/модулей)
    ↓
MdtPortal (оперативный дашборд)
    ↑ (кнопка "Выбор департаментов")
```

### Пользовательский опыт:

1. **Вход в систему:** Пользователь выбирает департамент и модуль
2. **MDT Portal:** Отображается оперативный дашборд
3. **Возврат:** Кнопка "Выбор департаментов" в левом сайдбаре
4. **Результат:** Возврат к выбору модулей для текущего департамента

## 🎨 Визуальное решение

### Расположение кнопки:
- **Позиция:** Верхняя часть сайдбара, под заголовком "Synapse Terminal"
- **Стиль:** `variant="outline"` с иконкой стрелки влево
- **Размер:** `size="sm"` для компактности

### Иерархия элементов:
```
┌─ Synapse Terminal ─┐
├─ Выбор департаментов ← НОВАЯ КНОПКА
├─ Оперативный дашборд
├─ Поиск
├─ Управление
└─ Инструменты
```

## 🚀 Преимущества решения

### 1. **Интуитивная навигация**
- Кнопка находится в логичном месте (сайдбар)
- Понятная иконка и текст
- Соответствует общему дизайну

### 2. **Гибкость**
- Поддержка двух режимов навигации
- Возможность расширения для других порталов
- Не нарушает существующую архитектуру

### 3. **Производительность**
- Использование React Router для SPA навигации
- Нет перезагрузки страницы
- Сохранение состояния приложения

### 4. **UX улучшения**
- Быстрый доступ к выбору департаментов
- Сохранение контекста (выбранный департамент)
- Плавные переходы
