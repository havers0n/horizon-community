# Отчет о реализации модуля "Поиск граждан" (PD)

## Обзор реализации

Модуль "Поиск граждан" был успешно реализован согласно техническому заданию. Модуль предоставляет комплексный интерфейс для поиска, просмотра и управления данными граждан в системе CAD/MDT.

## Реализованная функциональность

### 1. Поиск граждан с live search

**Компонент:** `PersonSearchWidget.tsx`

**Функциональность:**
- Поиск по имени/фамилии с автодополнением
- Поиск по номеру SSN (Social Security Number)
- Live search с debounce (300ms задержка)
- Отображение подсказок в реальном времени
- Индикатор загрузки во время поиска
- Обработка ошибок поиска

**Технические особенности:**
```typescript
// Live search с debounce
useEffect(() => {
  if (searchTimeoutRef.current) {
    clearTimeout(searchTimeoutRef.current);
  }

  if (searchTerm.length >= 2) {
    setIsLiveSearch(true);
    searchTimeoutRef.current = setTimeout(() => {
      searchCitizens(searchTerm);
      setIsLiveSearch(false);
    }, 300);
  }
}, [searchTerm, searchCitizens]);
```

## Техническая реализация

### State Management (Zustand)

**Store:** `useCitizenSearchStore`

**Состояние:**
```typescript
interface CitizenSearchState {
  suggestions: CitizenSearchResult[];
  selectedPerson: Citizen | null;
  showSuggestions: boolean;
  isLoading: boolean;
  error: string | null;
}
```

**Действия:**
- `searchCitizens(searchTerm)` - поиск граждан
- `selectPerson(person)` - выбор гражданина
- `clearSelection()` - очистка выбора
- `setShowSuggestions(show)` - управление отображением подсказок
- `clearError()` - очистка ошибок

### Типы данных

**Основные типы:**
```typescript
interface Citizen {
  id: string;
  firstName: string;
  lastName: string;
  dateOfBirth: string;
  address: string;
  imageUrl: string;
  gender?: string;
  weight?: string;
  height?: string;
  occupation?: string;
  ssn?: string;
  flags?: string[];
  addressFlags?: string[];
}

interface CitizenSearchResult {
  id: string;
  fullName: string;
  ssn?: string;
  address?: string;
  dateOfBirth?: string;
  imageUrl?: string;
}
```

### Моковые данные

Используются существующие моковые данные:
- `MOCK_CITIZENS_EXTENDED` - расширенные данные граждан
- `MOCK_VEHICLES` - данные транспортных средств
- `MOCK_WEAPONS` - данные оружия
- `MOCK_PETS` - данные питомцев
