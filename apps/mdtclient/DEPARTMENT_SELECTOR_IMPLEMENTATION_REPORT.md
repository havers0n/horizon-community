# Отчет о реализации системы выбора департаментов MDT

## 🎯 Цель проекта

Реализация системы выбора департаментов согласно техническому заданию с созданием выпадающего списка в верхней части интерфейса и модульной системы для каждого департамента.

## ✅ Выполненные задачи

### Шаг 1: Создание компонента выбора департамента

**Файл:** `src/components/DepartmentSelector.tsx`

#### Основные компоненты:

1. **Интерфейс Department:**
   - `id: string` - идентификатор департамента
   - `name: string` - полное название
   - `shortName: string` - короткое название
   - `icon: React.ComponentType` - иконка департамента
   - `color: string` - цветовая схема

2. **Поддерживаемые департаменты:**
   - **PD** (Police Department) - Правоохранительные органы
   - **FD** (Fire Department) - Пожарная служба
   - **MD** (Medical Department) - Медицинская служба
   - **CC** (Civilian Center) - Гражданские службы
   - **CD** (Civil Department) - Гражданский департамент
   - **Dispatch** - Диспетчерская служба

3. **Функциональность:**
   - Выпадающий список с иконками и цветовой индикацией
   - Анимация открытия/закрытия
   - Backdrop для закрытия при клике вне
   - Hover эффекты и переходы

### Шаг 2: Создание системы модулей департаментов

**Файл:** `src/components/DepartmentModules.tsx`

#### Структура модулей по департаментам:

1. **Police Department (PD):**
   - Поиск граждан
   - Поиск ТС
   - Поиск оружия
   - Поиск адресов
   - Составление отчетов
   - Просмотр отчетов
   - Уголовный кодекс
   - Управление офицерами
   - Журнал смен

2. **Fire Department (FD):**
   - Управление инцидентами
   - Отчеты о пожарах
   - Отслеживание оборудования
   - Отслеживание машин
   - Управление персоналом

3. **Medical Department (MD):**
   - Управление пациентами
   - Экстренные вызовы
   - Медицинские отчеты
   - Отслеживание скорой
   - Поиск болезней

4. **Civilian Center (CC):**
   - Регистрация граждан
   - Регистрация ТС
   - Регистрация оружия
   - Запросы документов
   - Журнал грузоперевозок
   - Компании
   - Питомцы
   - Кодексы

5. **Civil Department (CD):**
   - Управление гражданскими
   - Гражданские отчеты
   - Гражданские услуги

6. **Dispatch:**
   - Портал диспетчера
   - Управление вызовами
   - Управление юнитами
   - Управление BOLO
   - Управление ордерами
   - Карта
   - Сигналы
   - История вызовов

### Шаг 3: Интеграция в главную страницу

**Файл:** `src/pages/DashboardPage.tsx`

#### Ключевые изменения:

1. **Интеграция селектора департаментов:**
   - Размещение в верхней части интерфейса
   - Сброс выбранного модуля при смене департамента
   - Адаптивная компоновка с переключателем темы

2. **Система отображения модулей:**
   - Отображение списка модулей при отсутствии выбранного
   - Навигация между модулями
   - Кнопка "Назад к модулям"

3. **Обработка существующих порталов:**
   - Интеграция с DispatchPortal
   - Интеграция с MdtPortal
   - Fallback для новых модулей

## 🚀 Использование

### Базовое использование

```tsx
import { DepartmentSelector } from '@/components/DepartmentSelector';
import { DepartmentModules } from '@/components/DepartmentModules';

function App() {
  const [selectedDepartment, setSelectedDepartment] = useState('pd');
  const [selectedModule, setSelectedModule] = useState('');

  return (
    <div>
      <DepartmentSelector 
        selectedDepartment={selectedDepartment}
        onDepartmentChange={setSelectedDepartment}
      />
      <DepartmentModules
        selectedDepartment={selectedDepartment}
        onModuleSelect={setSelectedModule}
        selectedModule={selectedModule}
      />
    </div>
  );
}
```

### Навигация

1. **Выбор департамента:** Клик по селектору → Выбор из списка
2. **Выбор модуля:** Клик по карточке модуля
3. **Возврат:** Кнопка "Назад к модулям"
