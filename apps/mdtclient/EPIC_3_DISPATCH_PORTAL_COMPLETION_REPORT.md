### 1. Главный виджет `DispatchPortal`

**Файл:** `apps/mdtclient/src/widgets/dispatch-portal/ui/DispatchPortal.tsx`

**Ключевые особенности:**
- **Двухколоночная компоновка:** Левая колонка 60% (карта), правая колонка 40% (информационная панель)
- **Real-time интеграция:** Подключение к `useRealTime` хуку для получения актуальных данных
- **Динамические счетчики:** Активные юниты и вызовы обновляются в реальном времени
- **Статус подключения:** Индикатор онлайн/офлайн состояния системы

**Техническая реализация:**
```typescript
const { isConnected, stats, subscribe } = useRealTime(['units', 'calls', 'alerts']);

// Подписка на каналы при монтировании
useEffect(() => {
  subscribe(['units', 'calls', 'alerts']);
}, [subscribe]);

// Обновление счетчиков на основе реальных данных
useEffect(() => {
  setActiveUnitsCount(4); // Будет заменено на реальные данные
  setActiveCallsCount(2); // Будет заменено на реальные данные
}, [stats]);
```
