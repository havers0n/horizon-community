# Руководство по тестированию ролей и доступа к ядрам

## Проблема
Кнопка "Ядро экстренных служб" отображается как неактивная для гражданских пользователей.

## Решение
Добавлена система отладки ролей для тестирования доступа к различным ядрам.

## Как протестировать

### 1. Панель отладки ролей
В правом верхнем углу интерфейса (только в режиме разработки) появится кнопка "Отладка ролей".

### 2. Доступные тестовые роли
- **Гражданский** - только Civil Core
- **Полиция** - оба ядра (Emergency Core по умолчанию)
- **Диспетчер** - оба ядра
- **Скорая** - оба ядра
- **Пожарные** - оба ядра
- **Админ** - оба ядра

### 3. Пошаговое тестирование

#### Тест 1: Гражданский пользователь
1. Нажмите "Отладка ролей"
2. Выберите "Гражданский"
3. Проверьте, что доступен только Civil Core
4. Кнопка "Ядро экстренных служб" должна быть неактивна

#### Тест 2: Полиция
1. Нажмите "Отладка ролей"
2. Выберите "Полиция"
3. Проверьте, что по умолчанию открывается Emergency Core
4. Проверьте, что доступны оба ядра
5. Переключитесь на Civil Core и обратно

#### Тест 3: Другие экстренные службы
1. Протестируйте роли: Диспетчер, Скорая, Пожарные, Админ
2. Убедитесь, что все имеют доступ к обоим ядрам

### 4. Проверка через консоль браузера
```javascript
// Установить роль полиции
RoleDebugger.setTestRole('leo');

// Установить гражданскую роль
RoleDebugger.setTestRole('civilian');

// Очистить тестовую роль
RoleDebugger.clearTestRole();

// Проверить текущую роль
RoleDebugger.getTestRole();
```

## Ожидаемое поведение

### Гражданский пользователь
- ✅ Доступен Civil Core
- ❌ Emergency Core недоступен (кнопка неактивна)
- ✅ Автоматически открывается Civil Core

### Экстренные службы (leo, dispatch, ems, fire, admin)
- ✅ Доступен Civil Core
- ✅ Доступен Emergency Core
- ✅ Автоматически открывается Emergency Core
- ✅ Можно переключаться между ядрами

## Отладка

### Проверка ролей в консоли
```javascript
// Проверить текущие роли пользователя
console.log('User roles:', window.RoleDebugger.getTestRole());

// Проверить доступ к ядрам
const roles = window.RoleDebugger.getTestRole();
const canAccessEmergency = roles.some(role => ['leo', 'dispatch', 'ems', 'fire', 'admin'].includes(role));
console.log('Can access Emergency Core:', canAccessEmergency);
```

### Логи в консоли
Следите за логами в консоли браузера:
- `[useUserRoles] Using test roles: [...]`
- `[AuthenticatedApp] Initializing default core for user: ... with roles: ...`
- `[CoreSwitcher] Switching to emergency core`

## Устранение проблем

### Проблема: Роли не применяются
1. Проверьте, что localStorage доступен
2. Очистите кэш браузера
3. Перезагрузите страницу

### Проблема: Кнопка остается неактивной
1. Проверьте консоль на ошибки
2. Убедитесь, что роль установлена правильно
3. Проверьте, что `canAccessCore` возвращает `true`

### Проблема: Неправильное ядро по умолчанию
1. Проверьте логи инициализации
2. Убедитесь, что `determineDefaultCore` работает корректно
3. Проверьте, что роли передаются правильно
