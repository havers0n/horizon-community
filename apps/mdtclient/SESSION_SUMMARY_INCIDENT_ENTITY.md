## 🎯 Готово к использованию

### Импорт и использование
```typescript
// Импорт всех компонентов
import { 
  Incident, 
  IncidentApi, 
  IncidentCard, 
  IncidentList, 
  IncidentDetails 
} from '@/entities/incident';

// Создание инцидента
const newIncident = await IncidentApi.createIncident({
  type: IncidentType.CRIMINAL,
  priority: IncidentPriority.HIGH,
  severity: IncidentSeverity.MAJOR,
  title: 'Ограбление банка',
  description: 'Вооруженное ограбление центрального банка',
  location: { address: '123 Main St', city: 'Los Santos', state: 'CA', zipCode: '90210' },
  category: IncidentCategory.THEFT,
  reporter: { name: 'John Doe', phone: '+1234567890', isAnonymous: false }
});

// Поиск инцидентов
const incidents = await IncidentApi.searchIncidents({
  type: [IncidentType.CRIMINAL, IncidentType.TRAFFIC],
  status: [IncidentStatus.ACTIVE],
  priority: [IncidentPriority.HIGH, IncidentPriority.CRITICAL],
  limit: 50
});
```
