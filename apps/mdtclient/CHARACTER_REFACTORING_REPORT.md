### API Endpoints
Все API вызовы обновлены для работы с правильными эндпоинтами:
- `GET /api/characters` - получение списка персонажей
- `GET /api/characters/:id` - получение персонажа по ID
- `POST /api/characters` - создание персонажа
- `PUT /api/characters/:id` - обновление персонажа
- `DELETE /api/characters/:id` - удаление персонажа
