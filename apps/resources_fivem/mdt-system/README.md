# MDT System - RolePlayIdentity (Framework Independent)

Система MDT (Mobile Data Terminal) для FiveM сервера RolePlayIdentity. **Полностью независима от фреймворков**.

## 🎯 Основные изменения в версии 2.0.0

- ✅ **Удалена зависимость от ESX/QBCore**
- ✅ **Универсальная система разрешений**
- ✅ **Гибкая конфигурация**
- ✅ **Встроенная система безопасности**
- ✅ **Кэширование и оптимизация**
- ✅ **Rate limiting для защиты от спама**
- ✅ **Исправлена проблема автоматического открытия MDT**

## 🚨 Важное исправление: Автоматическое открытие MDT

**Проблема решена!** MDT больше не открывается автоматически при старте ресурса.

### Быстрое решение:
```bash
# В консоли сервера для немедленного закрытия MDT у всех игроков
mdt_close_all
```

### Подробная документация:
См. файл `AUTO_OPEN_FIX.md` для полного описания решения.

## Описание

MDT System предоставляет полнофункциональный интерфейс для правоохранительных органов, позволяющий:
- Поиск информации о гражданах
- Создание и управление отчетами
- Поиск транспортных средств
- Управление ордерами на арест
- Административные функции

## 🚀 Установка

1. Скопируйте папку `mdt-system` в директорию `resources` вашего FiveM сервера
2. Настройте `config.lua` под ваш сервер
3. Добавьте `ensure mdt-system` в ваш `server.cfg`
4. Перезапустите сервер

## ⚙️ Конфигурация

### Основные настройки в `config.lua`:

```lua
-- Разрешенные профессии
Config.AllowedJobs = {
    'police',
    'sheriff', 
    'fbi',
    'admin'
}

-- Режим работы (Standalone/ESX/QBCore)
Config.Framework = {
    standalone = {
        enabled = true  -- Рекомендуется
    },
    esx = {
        enabled = false -- Опционально
    },
    qbcore = {
        enabled = false -- Опционально
    }
}
```

### Интеграция с фреймворками (опционально)

Если хотите использовать с ESX или QBCore:

```lua
-- Для ESX
Config.Framework.esx.enabled = true
Config.Framework.standalone.enabled = false

-- Для QBCore  
Config.Framework.qbcore.enabled = true
Config.Framework.standalone.enabled = false
```

## 🎮 Использование

### Команды

- `/mdt` - Открыть MDT интерфейс
- `/mdt_admin reload` - Перезагрузить конфигурацию
- `/mdt_admin stats` - Показать статистику
- `/mdt_admin clear_cache` - Очистить кэш

### Горячие клавиши

- `F6` - Открыть/закрыть MDT
- `ESC` - Закрыть MDT (когда открыт)

## 🔧 API

### Клиентские события

```lua
-- Открыть MDT
TriggerEvent('mdt:open')

-- Закрыть MDT
TriggerEvent('mdt:close')
```

### Серверные события

```lua
-- Поиск гражданина
TriggerServerEvent('mdt:searchCitizen', identifier)

-- Сохранение отчета
TriggerServerEvent('mdt:saveReport', reportData)

-- Получение списка отчетов
TriggerServerEvent('mdt:getReports')
```

### Экспортируемые функции

```lua
-- Клиент
exports['mdt-system']:openMDT()
exports['mdt-system']:closeMDT()
exports['mdt-system']:isMDTOpen()

-- Сервер
exports['mdt-system']:hasPermission(source)
exports['mdt-system']:isAdmin(source)
exports['mdt-system']:searchCitizen(identifier)
exports['mdt-system']:saveReport(reportData)
```

## 🛡️ Безопасность

### Встроенные механизмы защиты:

- **Rate Limiting** - Ограничение количества запросов
- **Валидация данных** - Проверка всех входящих данных
- **Проверка разрешений** - Контроль доступа по профессиям
- **Логирование** - Запись всех действий
- **Кэширование** - Защита от повторных запросов
- **Защита от автоматического открытия** - MDT не открывается автоматически

### Настройки безопасности:

```lua
Config.Security = {
    require_permission = true,
    log_unauthorized_access = true,
    rate_limit = {
        enabled = true,
        max_requests = 10,
        time_window = 60
    }
}
```

## 🐛 Устранение неполадок

### Частые проблемы:

1. **MDT не открывается**
   - Проверьте настройки разрешений в `config.lua`
   - Убедитесь, что у игрока правильная профессия

2. **MDT открывается автоматически**
   - Используйте команду `/mdt_close_all` для немедленного закрытия
   - См. файл `AUTO_OPEN_FIX.md` для подробного решения

3. **Ошибки в консоли**
   - Проверьте логи сервера
   - Убедитесь, что все файлы загружены

4. **Проблемы с производительностью**
   - Настройте кэширование в `config.lua`
   - Проверьте настройки rate limiting
