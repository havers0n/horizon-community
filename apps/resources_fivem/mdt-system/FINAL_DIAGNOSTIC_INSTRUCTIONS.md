# Финальные инструкции по диагностике MDT System

## Проблема
Пользователь сообщает, что MDT:
1. Открывается автоматически при старте ресурса
2. Не реагирует на нажатие F6

**ВАЖНО:** Логи показывают корректную работу системы, но пользователь сообщает о противоположном поведении.

## Пошаговая диагностика

### Шаг 1: Перезапуск ресурса
```lua
restart mdt-system
```

### Шаг 2: Ожидание полной загрузки (15 секунд)
Подождите 15 секунд после старта ресурса для полной инициализации.

### Шаг 3: Полная диагностика
```lua
/mdt_full_diagnostic
```

**Проверьте следующие значения:**
- `isMDTOpen = false` (MDT должен быть закрыт)
- `resourceStarting = false` (ресурс должен быть полностью загружен)
- `configLoaded = true` (конфигурация должна быть загружена)
- `keyBindingRegistered = true` (привязка клавиш должна быть зарегистрирована)
- `timeSinceStart = [число больше 10000]` (должно пройти больше 10 секунд)
- `autoOpenAttempts = 0` (не должно быть попыток автоматического открытия)
- `nuiCallbackCount = 0` (не должно быть NUI callback'ов)

### Шаг 4: Проверка состояния
```lua
/mdt_status
```

### Шаг 5: Тестирование F6 логики
```lua
/mdt_test_f6
```

**Ожидаемый результат:**
```
[MDT System] === ТЕСТ F6 ===
[MDT Test] Все проверки пройдены - выполняем действие
[MDT Test] MDT закрыт - открываем
[MDT System] === ТЕСТ F6 ЗАВЕРШЕН ===
```

### Шаг 6: Мониторинг в реальном времени
```lua
/mdt_monitor
```

### Шаг 7: Тестирование физической клавиши F6
1. Нажмите F6
2. Проверьте логи на наличие:
   ```
   [MDT Debug] === F6 НАЖАТА ===
   [MDT Debug] Время нажатия F6: [число]
   [MDT Debug] isMDTOpen = false
   [MDT Debug] NUI Focus = false
   [MDT Debug] resourceStarting = false
   [MDT Debug] configLoaded = true
   [MDT Debug] keyBindingRegistered = true
   [MDT Debug] Время с момента старта: [число больше 10000]
   ```

### Шаг 8: Проверка NUI интерфейса
1. Откройте MDT (через команду `/mdt_force_open_debug` или F6)
2. Проверьте, что отображается тестовый интерфейс с заголовком "MDT Test Interface"
3. Нажмите F6 в интерфейсе
4. Проверьте логи NUI на наличие:
   ```
   [MDT Test] Клавиша нажата: F6 (код: 117)
   [MDT Test] Отправляем команду закрытия MDT (F6)
   ```

## Команды для экстренной диагностики

### Полная диагностика системы
```lua
/mdt_full_diagnostic
```

### Принудительное открытие (обход всех проверок)
```lua
/mdt_force_open_debug
```

### Принудительное закрытие (обход всех проверок)
```lua
/mdt_force_close_debug
```

### Очистка кэша
```lua
/mdt_clear_cache
```

### Остановка мониторинга
```lua
/mdt_monitor
```

## Возможные причины проблемы

### 1. Кэширование браузера
**Симптомы:** Логи показывают корректную работу, но визуально система не работает
**Решение:** 
```lua
/mdt_clear_cache
restart mdt-system
```

### 2. Конфликт с другими ресурсами
**Симптомы:** F6 не реагирует, но логи показывают корректную работу
**Решение:** Отключить другие ресурсы, которые могут использовать F6

### 3. Проблемы с NUI фокусом
**Симптомы:** NUI интерфейс не получает события клавиатуры
**Решение:** Проверить, что тестовый интерфейс отображается и имеет фокус

### 4. Проблемы с NUI коммуникацией
**Симптомы:** `nuiCallbackCount` не увеличивается при нажатии F6
**Решение:** Проверить логи NUI на наличие ошибок JavaScript

## Что делать, если проблема сохраняется

1. **Выполните полную диагностику:**
   ```lua
   /mdt_full_diagnostic
   ```

2. **Предоставьте полные логи** после выполнения всех шагов

3. **Опишите визуальное поведение:**
   - Открывается ли MDT автоматически?
   - Отображается ли тестовый интерфейс?
   - Реагирует ли F6 на нажатие?

4. **Проверьте консоль браузера** на ошибки JavaScript

5. **Сделайте скриншот или видео** для демонстрации проблемы

6. **Проверьте конфликты** с другими ресурсами

## Ожидаемое поведение после исправлений

1. **При старте ресурса:** MDT НЕ должен открываться автоматически
2. **Через 10 секунд после старта:** F6 должна работать корректно
3. **При нажатии F6:** MDT должен открываться/закрываться
4. **При нажатии ESC:** MDT должен закрываться
5. **В тестовом интерфейсе:** Все события должны логироваться
