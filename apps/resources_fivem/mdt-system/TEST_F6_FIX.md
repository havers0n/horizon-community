# 🧪 ТЕСТИРОВАНИЕ ИСПРАВЛЕНИЯ F6

## 🔧 Что было исправлено

1. **Обновлен NUI скрипт** - добавлена поддержка `event.which` для лучшего определения клавиш
2. **Добавлен фокус на body** - для получения событий клавиатуры
3. **Создан тестовый интерфейс** - для диагностики проблем
4. **Улучшена диагностика** - добавлены дополнительные логи

## 🧪 Пошаговое тестирование

### Шаг 1: Запуск ресурса
```bash
restart mdt-system
```

### Шаг 2: Проверка логов
**Ожидаемые сообщения:**
```
[MDT System] MDT НЕ будет открываться автоматически!
[MDT System] MDT открывается ТОЛЬКО по клавише F6!
[MDT Test] Тестовый интерфейс загружен
[MDT Test] DOM загружен
```

### Шаг 3: Открытие MDT
1. **Подождите 10 секунд** после старта
2. **Нажмите F6**
3. **Проверьте консоль браузера** (F12) на наличие сообщений:
   ```
   [MDT Test] Клавиша нажата: F6 (код: 117)
   ```

### Шаг 4: Закрытие MDT
1. **Нажмите F6 еще раз** для закрытия
2. **Или нажмите ESC** для закрытия
3. **Проверьте логи сервера:**
   ```
   [MDT Test] F6 нажата - закрываем MDT
   [MDT Debug] Закрытие MDT по запросу UI (причина: F6_pressed)
   [MDT System] MDT закрыт
   ```

## 🔍 Диагностика

### Если F6 не работает:
1. **Откройте консоль браузера** (F12)
2. **Проверьте сообщения:**
   - `[MDT Test] Клавиша нажата:` - показывает, получает ли интерфейс события клавиатуры
   - `[MDT Test] Фокус: Есть` - показывает, есть ли фокус у интерфейса

### Если интерфейс не открывается:
1. **Проверьте логи сервера** на наличие ошибок
2. **Убедитесь, что прошло 10 секунд** после старта ресурса

## 🎯 Ожидаемый результат

- ✅ MDT НЕ открывается автоматически при старте
- ✅ F6 открывает MDT (после 10 секунд)
- ✅ F6 закрывает MDT
- ✅ ESC закрывает MDT
- ✅ В консоли браузера видны сообщения о нажатии клавиш

## 🔄 Возврат к основному интерфейсу

После успешного тестирования верните основной интерфейс:

1. **Измените `fxmanifest.lua`:**
   ```lua
   ui_page 'ui/index.html'
   
   files {
       'ui/index.html',
       'ui/index.css',
       'ui/index.js'
   }
   ```

2. **Перезапустите ресурс:**
   ```bash
   restart mdt-system
   ```
