# 🚀 ОТЧЕТ ОБ ИНТЕГРАЦИИ REACT ПРИЛОЖЕНИЯ С MDT СИСТЕМОЙ

## 🎯 ЦЕЛЬ
Интеграция собранного React приложения из `apps/mdtclient/` в MDT систему FiveM для использования полнофункционального интерфейса.

## 📁 СТРУКТУРА ФАЙЛОВ

### **Источник (apps/mdtclient/):**
- `dist-nui/index.html` - Собранный HTML файл
- `dist-nui/index.js` - Собранный JavaScript (550KB)
- `dist-nui/index.css` - Собранные стили (1.3KB)

### **Назначение (apps/resources_fivem/mdt-system/ui/):**
- `index.html` - Обновленный HTML с React приложением
- `index.js` - Скопированный собранный React код
- `index.css` - Скопированные собранные стили
- `nui-bridge.js` - Мост между FiveM NUI и React

## 🔄 АРХИТЕКТУРА КОММУНИКАЦИИ

```
FiveM Client (Lua) 
    ↓ NUI Callback
NUI Bridge (JavaScript)
    ↓ Window.postMessage
React Application
    ↓ Window.postMessage
NUI Bridge (JavaScript)
    ↓ fetch/$.post
FiveM Client (Lua)
```

### **Типы сообщений:**
- `MDT_OPEN` - Открытие MDT
- `MDT_CLOSE` - Закрытие MDT  
- `MDT_UPDATE_DATA` - Обновление данных
- `toggleMDT` - Переключение MDT (F6)
- `closeMDT` - Закрытие MDT (ESC)

## 🚀 ИНСТРУКЦИИ ПО ИСПОЛЬЗОВАНИЮ

### **Для разработки:**
1. **Сборка:** `cd apps/mdtclient && npm run build:fivem`
2. **Копирование:** Файлы автоматически копируются в `mdt-system/ui/`
3. **Тестирование:** `restart mdt-system`

### **Для пользователей:**
1. **Запуск:** `restart mdt-system`
2. **Ожидание:** 10 секунд после старта
3. **Открытие:** Нажать F6
4. **Использование:** Полный React интерфейс
