## 🚀 ИНСТРУКЦИИ ПО ИСПОЛЬЗОВАНИЮ

1. **Запустите ресурс:** `restart mdt-system`
2. **Подождите 10 секунд** после старта
3. **Нажмите F6** для открытия MDT
4. **Нажмите F6 еще раз** для закрытия MDT
5. **Или нажмите ESC** для закрытия MDT
