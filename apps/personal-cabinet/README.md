# Личный кабинет - RolePlay Identity

Второе приложение в монорепозитории, реализованное с использованием **FSD (Feature-Sliced Design)** и **Atomic React** архитектуры.

## 🏗️ Архитектура

### FSD (Feature-Sliced Design)
Приложение структурировано по слоям FSD:

```
src/
├── app/           # Инициализация приложения
├── pages/         # Страницы приложения
├── widgets/       # Композитные блоки
├── features/      # Бизнес-функции
├── entities/      # Бизнес-сущности
└── shared/        # Переиспользуемый код
```

### Atomic React
Компоненты организованы по принципу Atomic Design:

- **Atoms**: Базовые компоненты (Button, Card, Input)
- **Molecules**: Простые композиции (Form, SearchBar)
- **Organisms**: Сложные блоки (Header, Sidebar, Dashboard)
- **Templates**: Макеты страниц
- **Pages**: Полные страницы приложения

## 🎨 UI Компоненты

Приложение использует общую UI библиотеку `@shared/ui-components`, которая содержит:

- **Button** - кнопки с различными вариантами
- **Card** - карточки с заголовком, контентом и футером
- **Toast** - уведомления
- **Utils** - утилиты для работы с классами

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

Приложение доступно по адресу: http://localhost:3001

## 📁 Структура проекта

### Pages (Страницы)
- `dashboard/` - Главная страница с дашбордом
- `profile/` - Страница профиля пользователя
- `settings/` - Страница настроек
- `auth/login/` - Страница входа
- `auth/register/` - Страница регистрации

### Widgets (Виджеты)
- `dashboard/` - Виджет дашборда
- `profile/` - Виджет профиля
- `settings/` - Виджет настроек

### Features (Функции)
- `dashboard/stats/` - Статистика дашборда
- `dashboard/recent-activity/` - Последняя активность
- `dashboard/quick-actions/` - Быстрые действия
- `auth/login/` - Форма входа
- `auth/register/` - Форма регистрации

### Shared (Общие ресурсы)
- `ui/` - UI компоненты (реэкспорт из общей библиотеки)
- `lib/` - Утилиты и хелперы
- `types/` - TypeScript типы
- `api/` - API клиенты
- `config/` - Конфигурация

## 🔧 Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик
- **Tailwind CSS** - Стилизация
- **React Router** - Маршрутизация
- **TanStack Query** - Управление состоянием
- **Supabase** - Backend-as-a-Service
- **Radix UI** - Headless UI компоненты

## 🎯 Демонстрация

Приложение демонстрирует:

1. **FSD архитектуру** - четкое разделение на слои
2. **Atomic React** - компонентную архитектуру
3. **Переиспользование UI** - общую библиотеку компонентов
4. **TypeScript** - строгую типизацию
5. **Современный UI** - красивые и функциональные интерфейсы
