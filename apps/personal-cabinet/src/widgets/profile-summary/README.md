# ProfileSummaryWidget

Динамический компонент "Сводка Участника", который заменяет статичный виджет "Добро пожаловать" на главной странице дашборда.

## Описание

`ProfileSummaryWidget` загружает актуальную информацию о пользователе через RPC-функцию `get_my_dashboard_profile()` и отображает персонализированную сводку профиля участника.

## Возможности

### Динамическая загрузка данных
- Использует `useQuery` для вызова RPC-функции `get_my_dashboard_profile()`
- Автоматическое обновление данных каждые 5 минут
- Обновление при возврате фокуса на окно

### Отображаемая информация

#### 1. Заголовок приветствия
- Формат: "Добро пожаловать, {имя}!"
- Использует первое и последнее имя, если доступны
- Fallback на username, если имя недоступно

#### 2. Членства в департаментах
- Отображение основных и совмещаемых должностей
- Основные: "Департамент | Подразделение"
- Совмещение: "Департамент | Подразделение (Совмещение)"
- Показ звания под каждой должностью

#### 3. Квалификации
- Отображение в виде badges
- Показывается только если квалификации есть

#### 4. Предупреждения
- Блок отображается только при наличии предупреждений
- Раздельный счётчик для сообщества и игры
- Цветовое кодирование по количеству (зелёный/жёлтый/красный)

#### 5. Статус отпуска
- Специальная плашка "[🌴] В отпуске до {дата}"
- Отображается только если пользователь в отпуске

#### 6. Ссылка на полный профиль
- Всегда доступная ссылка "Посмотреть полный профиль" → `/profile`

### Состояния загрузки

#### Loading State
- Показывает `ProfileSummarySkeleton` во время загрузки
- Анимированные placeholder'ы для всех блоков данных

#### Error State
- Показывает пользовательское сообщение об ошибке
- Предложение обновить страницу

## Типы данных

### DashboardProfileData
Основной тип данных, возвращаемых RPC-функцией:

```typescript
interface DashboardProfileData {
  user: {
    id: string;
    username: string | null;
    first_name?: string | null;
    last_name?: string | null;
  };
  memberships: Array<{
    department_name: string;
    division_name?: string | null;
    rank_name: string;
    is_primary: boolean;
  }>;
  qualifications: Array<{
    id: string;
    name: string;
    code?: string;
  }>;
  warnings: {
    community: number;
    game: number;
  };
  leave_status: {
    is_on_leave: boolean;
    end_date?: string | null;
  } | null;
}
```

## RPC-функция

Компонент ожидает, что на бэкенде реализована RPC-функция `get_my_dashboard_profile()`, которая:

1. Возвращает полную информацию о текущем пользователе
2. Включает все членства (основные и совмещения) 
3. Предоставляет актуальные квалификации
4. Содержит количество предупреждений
5. Включает статус отпуска (если применимо)

## Стилизация

Компонент использует семантические цвета из дизайн-системы:
- `text-primary` для основного текста
- `text-muted-foreground` для второстепенного текста  
- `bg-success/10`, `bg-warning/10`, `bg-destructive/10` для предупреждений
- `border-t` для разделителя перед ссылкой на профиль

Покрытие тестами включает:

- Показ статуса отпуска

- Fallback для имени пользователя

## Миграция

Этот компонент заменяет старый `ProfileWidget` из `@/widgets/dashboard/ui/profile-widget`. Ключевые отличия:

1. **Данные**: Загружает данные динамически вместо получения их через props
2. **Функциональность**: Поддерживает множественные членства и квалификации  
3. **UX**: Показывает skeleton во время загрузки вместо пустого состояния
4. **Актуальность**: Автоматическое обновление данных
