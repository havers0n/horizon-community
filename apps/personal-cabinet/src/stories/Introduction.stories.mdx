# Personal Cabinet UI Components

Добро пожаловать в библиотеку UI компонентов для приложения Personal Cabinet!

## О проекте

Этот Storybook содержит все UI компоненты, используемые в приложении Personal Cabinet. Все компоненты построены на основе Radix UI и стилизованы с помощью Tailwind CSS.

## Структура компонентов

### Основные компоненты

- **Button** - Кнопки с различными вариантами и размерами
- **Input** - Поля ввода с поддержкой различных типов
- **Card** - Карточки для отображения контента
- **Badge** - Бейджи для статусов и меток
- **Avatar** - Аватары пользователей
- **Dialog** - Модальные окна и диалоги
- **Table** - Таблицы для отображения данных

### Формы

- **Form** - Компоненты для работы с формами
- **Label** - Метки для полей ввода
- **Checkbox** - Чекбоксы
- **Radio Group** - Группы радиокнопок
- **Select** - Выпадающие списки
- **Textarea** - Многострочные поля ввода

### Навигация

- **Breadcrumb** - Хлебные крошки
- **Tabs** - Вкладки
- **Accordion** - Аккордеоны
- **Navigation Menu** - Меню навигации

### Обратная связь

- **Alert** - Уведомления и предупреждения
- **Toast** - Всплывающие уведомления
- **Progress** - Индикаторы прогресса
- **Skeleton** - Скелетоны загрузки

### Дополнительные

- **Calendar** - Календарь
- **Popover** - Всплывающие подсказки
- **Tooltip** - Подсказки
- **Sheet** - Боковые панели
- **Scroll Area** - Области прокрутки

## Использование

Все компоненты готовы к использованию в production. Они полностью типизированы с помощью TypeScript и следуют принципам доступности (a11y).

### Пример использования

```tsx
import { Button } from '@/shared/ui/button';
import { Card, CardContent, CardHeader, CardTitle } from '@/shared/ui/card';

function MyComponent() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Заголовок карточки</CardTitle>
      </CardHeader>
      <CardContent>
        <p>Содержимое карточки</p>
        <Button>Действие</Button>
      </CardContent>
    </Card>
  );
}
```

## Темы

Компоненты поддерживают светлую и темную темы. Переключение между темами происходит автоматически в зависимости от системных настроек пользователя.

## Адаптивность

Все компоненты адаптивны и корректно отображаются на различных устройствах и размерах экранов.

## Доступность

Компоненты следуют стандартам WCAG 2.1 и включают:
- Поддержку клавиатурной навигации
- Правильную семантику HTML
- ARIA атрибуты
- Поддержку скринридеров

## Разработка

Для добавления новых компонентов:

1. Создайте компонент в `src/shared/ui/`
2. Добавьте story файл с расширением `.stories.tsx`
3. Обновите экспорты в `src/shared/ui/index.ts`
4. Добавьте документацию в MDX формате при необходимости

## Тестирование

Все компоненты покрыты unit тестами и интеграционными тестами. Используйте Storybook для визуального тестирования и проверки различных состояний компонентов.
