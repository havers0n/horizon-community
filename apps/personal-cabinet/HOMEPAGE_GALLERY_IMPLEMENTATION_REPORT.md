### 2. **Система галереи (Gallery)**

#### ✅ Создана полная FSD архитектура:
```
src/features/gallery/
├── ui/
│   ├── gallery-widget.tsx      # Основной виджет
│   ├── gallery-filter.tsx      # Фильтр по департаментам
│   ├── gallery-grid.tsx        # Сетка изображений
│   ├── gallery-lightbox.tsx    # Лайтбокс для просмотра
│   └── gallery-upload.tsx      # Загрузка (для админов)
├── model/
│   └── types.ts                # Типы данных
└── index.ts                    # Экспорты
```

#### ✅ Функциональность галереи:
- **Фильтрация по департаментам** (Все, LSPD, SAMS, SAFR, SAHP, DD, CD)
- **Сетка изображений** с hover-эффектами
- **Лайтбокс для просмотра** с детальной информацией
- **Счетчик изображений** (показано X из Y)
- **Пустое состояние** при отсутствии изображений
- **Адаптивный дизайн** для всех устройств

#### ✅ Данные галереи:
- 8 изображений с описаниями
- Метаданные: название, описание, департамент, дата, автор
