# Руководство по переключению между интерфейсами

## Обзор

Система RolePlay Identity состоит из нескольких интерфейсов, работающих на разных портах:

- **Основной интерфейс** (порт 3000) - главная панель управления
- **MDT System** (порт 3001) - система управления данными
- **CAD System** (порт 3002) - система диспетчеризации

## Способы переключения

### 1. Через кнопку переключения интерфейсов

В правом верхнем углу основного интерфейса находится кнопка "Основной интерфейс" с выпадающим меню. При клике на неё открывается список доступных интерфейсов:

- **Основной интерфейс** - возврат на главную панель
- **MDT System** - переход в систему управления данными
- **CAD System** - переход в систему диспетчеризации

### 2. Прямые ссылки

Можно использовать прямые ссылки:
- `http://localhost:3000/` - основной интерфейс
- `http://localhost:3000/mdt` - MDT System (встроенный)
- `http://localhost:3000/cad` - CAD System (встроенный)

### 3. Прямой доступ к портам

- `http://localhost:3000` - основной интерфейс
- `http://localhost:3001` - MDT System (прямой доступ)
- `http://localhost:3002` - CAD System (прямой доступ)

## Запуск всех интерфейсов

### Автоматический запуск всех сервисов

```bash
# Запуск всех интерфейсов одновременно
npm run dev:all
```

### Ручной запуск отдельных сервисов

```bash
# Основной интерфейс (порт 3000)
npm run dev:client

# MDT System (порт 3001)
npm run dev:mdt

# Сервер API (порт 5000)
npm run dev:server
```

## Особенности работы

### Встроенные интерфейсы

При переходе через кнопку переключения интерфейсы открываются в модальном окне с возможностями:

- **Обновление** - кнопка обновления интерфейса
- **Открыть в новой вкладке** - открытие интерфейса в отдельной вкладке
- **Закрытие** - возврат к основному интерфейсу

### Проверка доступности

Система автоматически проверяет доступность интерфейсов и показывает соответствующие сообщения:

- **Загрузка** - интерфейс загружается
- **Ошибка загрузки** - интерфейс недоступен
- **Интерфейс недоступен** - сервис не запущен

## Конфигурация

### Прокси настройки

В `apps/client/vite.config.ts` настроены прокси для переключения между интерфейсами:

```typescript
proxy: {
  '/mdt': {
    target: 'http://127.0.0.1:3001',
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/mdt/, ''),
  },
  '/cad': {
    target: 'http://127.0.0.1:3002',
    changeOrigin: true,
    rewrite: (path) => path.replace(/^\/cad/, ''),
  },
}
```

### Настройка портов

Порты можно изменить в соответствующих конфигурационных файлах:

- **Основной интерфейс**: `apps/client/package.json` → `"dev": "vite --port 3000"`
- **MDT System**: `apps/mdtclient/package.json` → `"dev": "vite --port 3001"`
- **CAD System**: настройте в соответствующем конфигурационном файле

## Устранение неполадок

### Интерфейс не загружается

1. Убедитесь, что все сервисы запущены
2. Проверьте, что порты не заняты другими приложениями
3. Проверьте консоль браузера на наличие ошибок

### Кнопка переключения не работает

1. Обновите страницу
2. Проверьте, что JavaScript включен
3. Проверьте консоль браузера на наличие ошибок

### Проблемы с прокси

1. Убедитесь, что Vite сервер запущен
2. Проверьте настройки прокси в `vite.config.ts`
3. Перезапустите сервер разработки

## Рекомендации

1. **Используйте автоматический запуск** - `npm run dev:all` для запуска всех сервисов
2. **Проверяйте доступность** - убедитесь, что все порты свободны перед запуском
3. **Используйте встроенные интерфейсы** - они обеспечивают лучший пользовательский опыт
4. **Открывайте в новой вкладке** - для длительной работы с MDT или CAD системами
